# 线性回归（Linear Regression）

> 掌握度：🟡 接触过 ｜ 所属模块：神经网络基础与闭环

## 一句话直觉
线性回归是整个深度学习大厦的**“地基第一砖”**：它用一条最简单的直线（或高维超平面）去拟合数据规律。**它本质上就是一个没有激活函数的单层单神经元网络**——麻雀虽小五脏俱全，仅用 $y = \mathbf{w}^T\mathbf{x} + b$ 和均方误差（MSE），就完整演示了“① 矩阵运算 $\to$ ② 架构表达 $\to$ ③ 损失打分 $\to$ ④ 梯度下降更新”这套贯穿所有深度学习算法的核心闭环。

---

## 核心要点与数学公式

### 1. 紧凑矩阵形式（前向推演）
对于包含 $N$ 个样本、每个样本具有 $D$ 维特征的数据集：
$$\hat{\mathbf{y}} = \mathbf{X}\mathbf{w} + b$$
- $\mathbf{X} \in \mathbb{R}^{N \times D}$：输入特征设计矩阵；
- $\mathbf{w} \in \mathbb{R}^{D \times 1}$：权重向量（每个维度的斜率/重要性）；
- $b \in \mathbb{R}$：偏置标量（广播到各样本）；
- $\hat{\mathbf{y}} \in \mathbb{R}^{N \times 1}$：模型连续预测值。

---

### 2. 损失函数：均方误差（MSE Loss）
衡量预测值 $\hat{\mathbf{y}}$ 与真实标签 $\mathbf{y}$ 之间的欧式距离平方和：
$$\mathcal{L}(\mathbf{w}, b) = \frac{1}{2N} \|\hat{\mathbf{y}} - \mathbf{y}\|_2^2 = \frac{1}{2N} \sum_{i=1}^{N} (\mathbf{w}^T \mathbf{x}^{(i)} + b - y^{(i)})^2$$

> 💡 **为什么前面乘 $\frac{1}{2}$？**
> 纯粹为了求导时常数 $2$ 与 $\frac{1}{2}$ 刚好抵消，让梯度公式保持简洁优雅。

---

### 3. 两种求解范式对比：解析解 vs 梯度下降

| 求解方式 | 核心公式 | 优点 | 致命缺陷（为何无法支撑深度学习） |
| :--- | :--- | :--- | :--- |
| **解析解（正规方程）** | $\mathbf{w}^* = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$ | 一步到位直接算出全局最优解 | 矩阵求逆时间复杂度 $\mathcal{O}(D^3)$；数据量大时内存放不下；**无法推广到多层非线性网络** |
| **迭代解（梯度下降）** | $\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \cdot \frac{1}{N}\mathbf{X}^T(\hat{\mathbf{y}} - \mathbf{y})$ | 显存占用极小，支持批次流式训练 | 需要调节学习率 $\eta$，需要多次迭代收敛 |

$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = \frac{1}{N} \mathbf{X}^T (\hat{\mathbf{y}} - \mathbf{y}), \qquad \frac{\partial \mathcal{L}}{\partial b} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}^{(i)} - y^{(i)})$$

---

### 4. 线性回归向现代神经网络的演进谱系

```
【线性回归】             y = w·x + b (连续值拟合，MSE)
    │
    ▼ (加入激活函数 σ)
【神经元模型/对率回归】   y = σ(w·x + b) (引入决策超平面，二分类)
    │
    ▼ (层级堆叠 + 隐藏层)
【多层感知机 MLP】        h1 = σ(W1·x + b1),  y = W2·h1 + b2 (高维非线性拟合)
```

## 最小验证代码（纯 NumPy 完整 4 步闭环）

```python
import numpy as np

# 1. 构造合成真实数据 (y = 2.5 * x - 1.2 + 噪声)
np.random.seed(42)
X = np.random.randn(100, 1)
y_true = 2.5 * X - 1.2 + np.random.randn(100, 1) * 0.1

# 2. 初始化可学习参数
w = np.random.randn(1, 1)
b = np.zeros((1, 1))
lr = 0.1

# 3. 梯度下降训练闭环 (50 轮迭代)
for epoch in range(50):
    # ① 前向预测
    y_pred = np.dot(X, w) + b
    
    # ② 计算 MSE Loss
    loss = np.mean(0.5 * (y_pred - y_true) ** 2)
    
    # ③ 逆向求导计算梯度
    dw = np.dot(X.T, (y_pred - y_true)) / len(X)
    db = np.sum(y_pred - y_true) / len(X)
    
    # ④ 梯度更新
    w -= lr * dw
    b -= lr * db

print(f"拟合结果 -> 权重 w: {w[0,0]:.4f} (真实值 2.5) | 偏置 b: {b[0,0]:.4f} (真实值 -1.2)")
```

## 工程与业务映射

- **PyTorch 中的最简对应**：
  `nn.Linear(in_features=D, out_features=1)` 本质上就是一个完整的线性回归算子。
- **YOLO 目标检测中的边界框回归头**：
  YOLO 输出的框偏移量 $(\Delta x, \Delta y, \Delta w, \Delta h)$ 就是多任务输出头中的线性回归分支，损失函数采用 CIoU / Smooth-L1 等回归损失。

## 思考与自测

- **自测 1**：为什么在深度学习中，哪怕线性回归有解析解 $(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$，我们仍然要教大家用梯度下降去优化它？
  > *解析*：因为解析解依赖矩阵可逆和全局凸性，一旦堆叠了多层隐藏层与非线性激活函数，解析解在数学上便彻底不复存在。梯度下降是唯一能够跨越浅层线性与千亿参数大模型的**通用优化范式**。
- **自测 2**：如果把 10 个线性回归层直接首尾相连串联起来（不加任何激活函数），它的拟合能力是否等同于 10 层深度神经网络？
  > *解析*：不等同。多层纯线性矩阵连乘 $W_{10} \dots W_1 \mathbf{x}$ 在代数上完全退化为单个矩阵 $W' \mathbf{x}$，表达能力依然被锁死在单层线性回归，无法拟合任何非线性曲线。

## 关联知识
- [[神经元模型]]：给线性回归加上激活函数 $\sigma$，即蜕变出能够划分非线性决策平面的神经元。
- [[损失函数]]：深入理解均方误差（MSE）与分类交叉熵的本质区别。
- [[梯度下降]]：沿着负梯度方向更新参数的动力学机制。
- [[多层感知机]]：线性回归通过多层堆叠与非线性激活构建的现代深度网络原型。
