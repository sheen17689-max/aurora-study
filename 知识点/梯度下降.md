# 梯度下降（Gradient Descent）

> 掌握度：🟡 接触过

## 一句话直觉
想象你被蒙上双眼置身于浓雾笼罩的山谷中，你用脚尖感受四周地面的坡度，每次都朝着**坡度最陡的下坡方向迈出一小步**，直到脚下地面变平（达到局部或全局损失最低点）。

## 核心要点与数学公式
- **参数更新核心公式**：
  $$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$
  其中 $\eta$ 为学习率（Learning Rate），$\nabla_\theta L(\theta)$ 为损失函数对参数的梯度向量。
- **三种经典变体**：
  1. **Batch GD**：每次用全量数据算梯度（稳但慢，显存装不下）；
  2. **SGD（随机梯度）**：每次只拿 1 个样本（快但震荡剧烈）；
  3. **Mini-Batch GD**：每次取小批量（如 32/64/128，现代深度学习标准配置）。
- **调优注意**：$\eta$ 过大导致损失震荡甚至出现 `NaN` 发散；$\eta$ 过小则收敛过慢甚至卡在鞍点。

## 最小验证代码（<20行纯 NumPy）
```python
import numpy as np

# 目标：求函数 f(w) = (w - 3)^2 的极小值（理论最优 w=3）
w = np.array([10.0])  # 初始猜测
lr = 0.1             # 学习率

for step in range(30):
    grad = 2 * (w - 3.0)     # 手动求导 df/dw
    w -= lr * grad           # 梯度更新
    loss = (w - 3.0) ** 2
    if step % 10 == 0 or step == 29:
        print(f"Step {step:02d} | w = {w[0]:.4f} | loss = {loss[0]:.6f}")
```

## 工程与业务映射
- **YOLO 训练配置**：在 YOLOv8 的 `args.yaml` 中配置 `lr0=0.01`, `lrf=0.01` 及 `optimizer=SGD/AdamW`，本质就是控制梯度下降的步长和动量衰减。
- **RKNN 部署感知**：量化模型前训练必须充分收敛，若权重震荡未达平坦局部最优，INT8 量化后的精度掉点会非常严重。

## 思考与自测
- **自测 1**：为什么不能根据当前梯度的方向“一步到位”直接走到底？
  > *解析*：梯度只是当前点的一阶导数（局部切线切平面方向），随着位置移动，损失曲面的曲率在不断改变，大跨步极容易越过谷底跨到另一侧陡坡。
- **自测 2**：当遇到鞍点（Saddle Point，导数为 0 但不是极小值）时，标准梯度下降会怎样？现代优化器（如 Momentum / Adam）是如何缓解的？

## 关联知识
- [[反向传播]]：负责计算出每一层权重的梯度 $\nabla_\theta L$ 供梯度下降使用。
- [[过拟合]]：训练迭代轮数（Epochs）过多时，梯度下降可能把训练集噪声也学进去。
