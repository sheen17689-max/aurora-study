# 随机森林（Random Forest 集成学习）

> 掌握度：⚪ 未学 ｜ 所属：七、经典机器学习（补充拓展） ｜ 更新：2026-08-19

## 一句话直觉
如果说单棵决策树是一个**一根筋的主管**——抱着一份数据从头问到尾，问题问偏了就全盘皆错；那么**随机森林就像召开一场几百人的评审会**：每位评委只随机看一部分材料、只被允许问部分问题，各自独立投票，最后少数服从多数——**个人的偏执在集体投票中被稀释，整体判断反而稳得多**。

---

## 核心要点与数学公式

### 1. 集成学习与 Bagging 思想
随机森林 = **Bagging（自助采样聚合）** + **决策树**。它不属于神经网络：没有权重、没有梯度、没有反向传播，推理靠的是一堆树投票。
- 分类任务：**多数投票**　$\hat{y} = \mathrm{mode}\{T_1(x), T_2(x), \dots, T_B(x)\}$
- 回归任务：**取均值**　$\hat{y} = \dfrac{1}{B} \sum_{b=1}^{B} T_b(x)$

### 2. 双重随机性（"随机"二字从哪来）
- **样本随机（Bootstrap 采样）**：每棵树从 $N$ 个样本中**有放回**地抽 $N$ 条，约 36.8% 的样本不会被抽到（袋外样本 OOB，可白嫖当验证集）；
- **特征随机**：每个节点分裂时，只允许从随机抽出的 $\sqrt{d}$（分类）或 $d/3$（回归）个特征里选最优切分点——这是防止"所有树犯同样错误"的关键。

### 3. 为什么投票能降低方差
设单棵树预测方差为 $\sigma^2$，树间相关性为 $\rho$，则 $B$ 棵树平均后的方差：
$$\mathrm{Var}(\bar{T}) = \rho\sigma^2 + \frac{(1-\rho)\sigma^2}{B}$$
- 树越多 $B \to \infty$，第二项趋于 0，但**第一项 $\rho\sigma^2$ 是地板**；
- **特征随机正是用来压低 $\rho$**——树与树越不像，集体方差越低。这也是随机森林优于纯 Bagging 的原因。

### 4. 单棵树怎么长：分裂准则
- **基尼指数**（CART 分类树默认）：$\mathrm{Gini} = 1 - \sum_{k} p_k^2$，越不纯越大；
- **信息熵**：$H = -\sum_{k} p_k \log_2 p_k$，选信息增益最大的特征切分；
- 回归树用**平方误差**做分裂与预测，一直长到叶子纯净或达到深度上限。

### 5. 与神经网络的工程差异速查
| 维度 | 随机森林 | 神经网络 |
|---|---|---|
| 训练方式 | 贪心递归切分，一次成型 | 梯度下降迭代优化 |
| 特征归一化 | **不需要**（只看排序切分） | 通常必须（防峡谷震荡） |
| 表格数据 | 极强，常是基线首选 | 通常不如树系模型 |
| 可解释性 | 特征重要性、OOB 误差 | 黑盒 |

## 最小验证代码（<20行纯 NumPy：101 棵树投票战胜单棵树）

```python
import numpy as np
rng = np.random.default_rng(42)
X = rng.normal(size=(300, 6)); y = (X[:, 0] + X[:, 1] > 0).astype(int)  # 仅前2维有效

def fit_stump(X, y, feats):            # 深度=1 的小树：选一个特征+阈值
    best, loss = None, np.inf
    for f in feats:
        for t in np.quantile(X[:, f], [0.33, 0.66]):
            lo = X[:, f] < t
            p = [y[lo].mean() if lo.any() else 0.5, y[~lo].mean() if (~lo).any() else 0.5]
            err = np.mean(np.where(lo, p[0], p[1]).round() != y)
            if err < loss: best, loss = (f, t, p), err
    return best

def pred(st, X): return np.where(X[:, st[0]] < st[1], st[2][0], st[2][1]).round()

single = pred(fit_stump(X, y, range(6)), X)                       # 单棵树：全特征
votes = []                                                        # 森林：双重随机
for _ in range(101):
    i = rng.integers(0, 300, 300)                                 # Bootstrap 采样
    votes.append(pred(fit_stump(X[i], y[i], rng.choice(6, 3, replace=False)), X))  # 随机3特征
forest = (np.mean(votes, axis=0) > 0.5).astype(int)               # 多数投票
print("单棵树:", (single == y).mean().round(3), "森林:", (forest == y).mean().round(3))
# 实测输出：单棵树: 0.763 森林: 0.84  ← 投票把弱模型抬成强模型
```

## 工程与业务映射

- **姿态评分的轻量基线（androidhub）**：
  - 把 YOLOv8n-Pose 输出的 COCO_17 关键点算成关节角度/肢体比例等特征，喂给随机森林做动作分类或打分，**CPU 即可毫秒级推理**，作为 JPSS/DTW 链路的对照基线或降级兜底方案；
  - 用**特征重要性**回答"哪些关节角度最影响评分"，辅助调试评分链路、发现关键点检测的错误绑定。
- **边缘端部署差异**：树模型不能跑 RKNN NPU，但 sklearn 模型可经 `skl2onnx` 导出 ONNX-ML 在 CPU 推理，体积小、无量化损耗；
- **什么时候选它不选神经网络**：表格型小数据（几百~几万行）、需要快速出基线、需要特征重要性解释时——先上随机森林，再决定要不要上深度模型。

## 思考与自测

- **自测 1**：随机森林的"随机"体现在哪两处？少了任何一处会怎样？
  > *解析*：① 每棵树训练样本做 Bootstrap 有放回采样；② 每个节点分裂时随机抽特征子集。只做样本随机（纯 Bagging）时，若数据里有一两个主导特征，所有树都会抢同一个特征分裂，树间高度相关 $\rho \to 1$，方差地板 $\rho\sigma^2$ 降不下去；特征随机正是打散这种同质化的关键。
- **自测 2**：随机森林需要像神经网络那样做 Z-Score 归一化吗？为什么？
  > *解析*：不需要。树的分裂只比较"特征值与阈值的大小关系"，对任何单调变换（缩放、平移、取 log）结果完全等价；归一化改变的是数值尺度，不改变排序，因此切分点与树结构不变。
- **自测 3**：树的数量 $B$ 越大越好吗？
  > *解析*：不是越大越好而是**越大越稳但不无限收益**。$B$ 增大只让方差公式中 $\frac{(1-\rho)\sigma^2}{B}$ 项趋近于 0，$\rho\sigma^2$ 地板不动；同时计算成本线性增长。实践中 100~500 棵后收益基本饱和。

## 关联知识
- [[过拟合]]：单棵深树是典型高方差模型，随机森林是"降方差"的教科书案例。
- [[模型评估指标]]：OOB 袋外误差是随机森林白送的验证集评估。
- [[数据预处理与归一化]]：树模型对单调变换免疫，是归一化规则的例外。
- [[组合神经网络]]：两条"弱模型变强"的路线对比——神经网络靠**组合**（层层嵌套提表达力），随机森林靠**投票**（并行平均降方差）。
