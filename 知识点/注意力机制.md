# 注意力机制（Attention Mechanism & Multi-Head Attention）

> 掌握度：🟡 接触过 ｜ 所属模块：序列模型与注意力

## 一句话直觉
注意力机制就是**“人类大脑的动态聚焦能力”**：当你在看一幅充满细节的油画时，你不会平等地平均扫描所有像素，而是视线迅速聚焦在画作的主角脸部（分配高权重），忽略模糊的背景（分配低权重）。在计算中，它通过 **$Q$（我要找什么）、$K$（你是什么特征标签）、$V$（你的具体内容）** 的点积匹配，实现了**在海量信息中动态加权提取最相关特征**的能力。

---

## 核心要点与数学公式

### 1. 经典 QKV 检索直觉映射
- **Query（查询向量 $Q$）**：当前神经元想寻找的信息（如“当前正在翻译主语”）；
- **Key（键向量 $K$）**：所有候选信息给出的“特征标签”；
- **Value（值向量 $V$）**：所有候选信息蕴含的“实质内容”。

---

### 2. 缩放点积注意力（Scaled Dot-Product Attention）

$$\text{Attention}(Q, K, V) = \text{Softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V$$

```
   Q ──┐
       ▼ (MatMul) ──▶ [QK^T 相似度矩阵] ──▶ [除以 √d_k 缩放] ──▶ [Softmax 概率加权] ──┐
   K ──┘                                                                             ▼ (MatMul) ──▶ 输出 Context
                                                                                 V ──┘
```

- **为什么要除以 $\sqrt{d_k}$ 缩放？**
  - 若向量维度 $d_k$ 很大（如 64 或 128），$Q K^T$ 点积结果的方差会扩大到 $d_k$。
  - 巨大的点积数值送入 Softmax 后，会导致概率分布极度陡峭（接近 One-hot，最大值逼近 1，其余全为 0），使得 Softmax 导数进入极其饱和的平坦区，**引发梯度消失**！除以 $\sqrt{d_k}$ 将方差重新拉回到 1.0 的平稳状态。

---

### 3. 多头注意力机制（Multi-Head Attention, MHA）
允许模型在**不同的子空间（Representation Subspaces）**同时关注不同维度的关联（如 1 号头关注主谓语法关系、2 号头关注代词指代、3 号头关注时态）：
$$\text{MHA}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$
$$\text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

## 最小验证代码（NumPy 手写标准 Scaled Dot-Product Attention）

```python
import numpy as np

# 模拟 1 个句子包含 3 个词, 隐藏维度 d_k = 4
# Q, K, V 形状: [Seq_Len=3, Dim=4]
np.random.seed(42)
Q = np.random.randn(3, 4)
K = np.random.randn(3, 4)
V = np.random.randn(3, 4)

d_k = Q.shape[-1]

# 1. 计算点积相似度得分矩阵: [3, 4] @ [4, 3] -> [3, 3]
scores = (Q @ K.T) / np.sqrt(d_k)

# 2. 沿行做 Softmax 归一化概率
exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)

# 3. 对 Value 进行加权聚合求和: [3, 3] @ [3, 4] -> [3, 4]
context_output = attn_weights @ V

print("注意力权重矩阵 (3x3 关联热力图):\n", attn_weights.round(3))
print("加权聚合后的输出特征:\n", context_output.round(3))
```

## 思考与自测

- **自测 1**：自注意力（Self-Attention）和交叉注意力（Cross-Attention）有什么区别？
  > *解析*：
  > - **Self-Attention（自注意力）**：$Q, K, V$ 全部来自**同一个输入序列**（同一个句子里的词相互算相关性）；
  > - **Cross-Attention（交叉注意力）**：$Q$ 来自目标端（Decoder 生成的查询），而 $K, V$ 来自源端（Encoder 提取的特征）。
