# 组合神经网络（Composing Neural Networks 与空间折叠）

> 掌握度：🟡 接触过

## 一句话直觉
如果说浅层网络是用剪刀在纸上剪几条直线折痕，那么**组合神经网络就像在玩“折纸艺术”**：第一层网络把输入空间对折一次，第二层在折好的纸上再对折，第三层继续对折——**只需几次对折（加深层数），就能以极少的参数在空间中创造出指数级爆炸的复杂结构与决策边界**。

---

## 核心要点与数学公式

### 1. 什么是组合（Function Composition）？
深度神经网络本质上就是多个简单浅层函数的**层层嵌套与复合**：
$$y = f_L(f_{L-1}(\dots f_2(f_1(\mathbf{x}))\dots))$$
每一层的输出 $h_{l-1}$ 直接作为下一层的输入：
$$\mathbf{h}_1 = \sigma(W_1 \mathbf{x} + \mathbf{b}_1)$$
$$\mathbf{h}_2 = \sigma(W_2 \mathbf{h}_1 + \mathbf{b}_2)$$
$$\dots$$
$$y = W_L \mathbf{h}_{L-1} + \mathbf{b}_L$$

---

### 2. 《理解深度学习》第 4 章几何洞见：超平面折叠（Space Folding）
- **浅层网络（1 个隐藏层）**：
  $K$ 个隐藏单元只能在输入空间切出 $K$ 条折痕，最多产生 $K+1$ 个分段线性区域（Linear Regions）。
- **深层组合网络（$L$ 个隐藏层）**：
  - 第 1 层网络沿着 ReLU 拐点把输入空间“对折”；
  - 第 2 层网络并不是作用在原始输入上，而是作用在**已经被折叠过的特征空间**上，折痕数量直接翻倍；
  - 第 $L$ 层网络可创造出多达 $\mathcal{O}(K^L)$ 个分段线性区域！

> 📐 **组合表达效率（Compositional Efficiency）**：
> - **参数量**：仅仅随层数 $L$ 呈**线性增长**（$\mathcal{O}(L \cdot K^2)$）；
> - **表达容量（线性区域数）**：随层数 $L$ 呈**指数级爆炸增长**（$\mathcal{O}(K^L)$）！
> 
> 这就是为什么**加深网络（Deep）**在参数效率上远超**单纯加宽网络（Wide）**的底层数学本质。

---

### 3. 为什么非线性激活函数是组合的灵魂？
如果激活函数是纯线性的 $\sigma(z) = z$，那么多层组合会发生**代数坍塌**：
$$y = W_3 (W_2 (W_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2) + \mathbf{b}_3 = (W_3 W_2 W_1) \mathbf{x} + \mathbf{b}' = W' \mathbf{x} + \mathbf{b}'$$
无论堆叠 100 层还是 1000 层，它在数学上都等价于**单层线性回归**，空间完全无法折叠，深度彻底失去意义。

## 最小验证代码（<20行纯 NumPy：两层组合折叠出 4 个锯齿波峰）

```python
import numpy as np

# 输入 1D 连续空间 [-1, 1]
x = np.linspace(-1, 1, 9)

# ---- 第 1 层组合: 将输入空间对称对折成 V 字形 ----
# h1 = ReLU(2x + 1), h2 = ReLU(-2x + 1)
h1_1 = np.maximum(0,  2.0 * x + 1.0)
h1_2 = np.maximum(0, -2.0 * x + 1.0)
folded_space = h1_1 + h1_2 - 1.0  # 空间已被折叠为 W 形 (2个拐点)

# ---- 第 2 层组合: 在已经折叠的空间上再次对折 (倍增为 4 个拐点) ----
h2_1 = np.maximum(0,  2.0 * folded_space - 1.0)
h2_2 = np.maximum(0, -2.0 * folded_space + 1.0)
y_out = h2_1 + h2_2

print("原始输入 x:        ", np.round(x, 2))
print("第 1 层折叠特征:    ", np.round(folded_space, 2))
print("第 2 层多重折叠输出:", np.round(y_out, 2))
```

## 工程与业务映射

- **YOLOv8 骨干网络的层级特征组合 (androidhub)**：
  - 浅层卷积层（Layer 1~4）：提取边缘、线条、颜色斑块（低级几何图元）；
  - 中层组合模块（C2f / CSPDarknet）：将线条组合为手肘、关节轮廓、手势几何形状；
  - 深层网络：将关节组合为完整的人体骨骼姿态评分与目标框。
  - **现实世界的物理结构本身就是层级嵌套的，组合神经网络的架构天生与物理现实同构！**
- **RKNN 嵌入式量化部署**：
  - NPU 芯片通过算子融合（Conv + BatchNorm + ReLU 融合为单个硬件指令）加速多层组合的流水线吞吐。

## 思考与自测

- **自测 1**：既然通用近似定理证明了单层极宽网络能逼近任意函数，为什么我们一定要用深层组合网络？
  > *解析*：因为**参数效率**天差地别。逼近一个高度振荡的复杂函数（如图像纹理或逻辑奇偶校验），浅层网络需要指数级（例如 $2^n$）个神经元才能平铺拼出来（宽度爆炸）；而深层网络通过层层折叠只需 $\mathcal{O}(n)$ 个神经元就能组合出来。
- **自测 2**：如果一个 5 层的神经网络中，第 3 层忘记写激活函数（变成了线性传导），这个网络会退化成 1 层吗？
  > *解析*：不会退化成 1 层，而是第 2 层和第 3 层的线性变换会合并为一层（$W_3 W_2 \to W'$），整个网络等价于只有 4 层的有效非线性组合深度。
