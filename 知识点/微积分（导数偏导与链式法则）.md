# 微积分（导数、偏导与链式法则）

> 掌握度：🟡 接触过 ｜ 所属模块：数学与数据地基

## 一句话直觉
微积分是深度学习模型的**“方向盘与油门传感器”**：导数告诉你往哪个方向走函数值会下降、下降得有多快；而链式法则就像**“传动齿轮组”**，不管多深、多复杂的复合流水线，都能把最终端输出的变化精确传递拆解到最前端每一个输入旋钮上。

---

## 核心要点与数学公式

### 1. 导数与偏导数（Derivative & Partial Derivative）
- **一元函数导数（斜率）**：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$
- **多元函数偏导数（固定其余变量，只对一个变量求导）**：
  $$\frac{\partial f(x_1, x_2)}{\partial x_1} = \lim_{\Delta x_1 \to 0} \frac{f(x_1 + \Delta x_1, x_2) - f(x_1, x_2)}{\Delta x_1}$$
- **梯度向量（Gradient Vector）**：函数在各坐标轴偏导数组成的向量，指向函数值**上升最快**的方向：
  $$\nabla f(\mathbf{x}) = \left[ \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right]^T$$

---

### 2. 微积分链式法则（Chain Rule）
深度学习本质是一个超深层的复合函数：$y = f(g(h(x)))$。

- **单变量复合求导**：若 $z = f(y)$ 且 $y = g(x)$，则：
  $$\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$$
- **多元多路径汇聚求导**：若 $z = f(u, v)$，而 $u = g(x), v = h(x)$，则总导数为两条支路之和：
  $$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}$$
  （这正是 ResNet 残差连接和多分支网络反向求导的数学依据！）

## 最小验证代码（NumPy 手写数值微分 vs 解析微分）

```python
import numpy as np

# 目标复合函数: f(x) = (2x + 3)^2
def f(x):
    return (2 * x + 3) ** 2

# 1. 解析微分 (链式法则: 2 * (2x + 3) * 2 = 8x + 12)
x_val = 4.0
analytic_grad = 8 * x_val + 12  # = 44.0

# 2. 数值微分 (中心差分法验证)
eps = 1e-6
numerical_grad = (f(x_val + eps) - f(x_val - eps)) / (2 * eps)

print(f"解析导数 (链式法则): {analytic_grad:.6f}")
print(f"数值导数 (极限逼近): {numerical_grad:.6f}")
print(f"相对误差: {abs(analytic_grad - numerical_grad):.1e}")
```

## 工程与业务映射

- **梯度检验（Gradient Check / Gradcheck）**：
  - 在手写自定义 PyTorch C++ / CUDA / RKNN 算子时，必须使用上述中心差分数值微分与手写的 `backward()` 解析导数进行对比，误差小于 $10^{-7}$ 才算通过验证。
- **雅可比矩阵（Jacobian）与海森矩阵（Hessian）**：
  - 一阶导数矩阵为雅可比矩阵；二阶导数矩阵为海森矩阵（衡量曲率）。现代深度学习由于海森矩阵占用 $O(N^2)$ 显存巨大，基本采用一阶梯度优化。

## 思考与自测

- **自测 1**：在计算图反向传播中，为什么多分支汇聚节点（如 $z = x + x$ 或残差相加）的梯度要把各分支传回的梯度相加？
  > *解析*：根据多元微积分全微分链式法则，自变量 $x$ 沿多条独立路径对最终输出造成影响时，总偏导数等于各路径分偏导数的代数和（$\frac{\partial L}{\partial x} = \sum_i \frac{\partial L}{\partial \text{path}_i} \frac{\partial \text{path}_i}{\partial x}$）。
