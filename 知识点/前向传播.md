# 前向传播（Forward Propagation）数学全景详解

> 掌握度：🟡 接触过

## 一句话直觉
前向传播就像一家**精密组装工厂**：原料（输入数据 $X$）进入流水线，经过每一道工序的**“加权线性混合”**（$W \cdot X + b$）与**“非线性质检折叠”**（激活函数 $\sigma$），层层推进，在末端产出预测值 $\hat{y}$，并与标准答案 $y$ 比对算出误差（$\text{Loss}$）。

---

## 📌 符号速查字典（先看懂符号，公式就不再可怕）

深度学习公式中经常出现各种上下标，只要记住这 3 条规则：
- **上标中括号 $[l]$**：代表**第 $l$ 层网络**（例如 $W^{[1]}$ 是第 1 层的权重矩阵，$A^{[0]} = X$ 是初始输入数据）；
- **上标小括号 $(i)$**：代表**第 $i$ 个训练样本**（例如 $x^{(2)}$ 是数据集里的第 2 张图片）；
- **下标 $j, k$**：代表矩阵的**行与列**（或者第 $j$ 个神经元接收来自上一层第 $k$ 个神经元的信号）。

| 符号 | 含义 | 作用 | 常见维度示例 |
| :--- | :--- | :--- | :--- |
| $X = A^{[0]}$ | 初始输入矩阵 | 原始特征数据（如图片像素、传感器读数） | $(N, D_{\text{in}})$ |
| $W^{[l]}$ | 第 $l$ 层的权重矩阵 | 决定上一层各个特征对本层神经元的重要程度 | $(D_{\text{in}}, D_{\text{out}})$ |
| $b^{[l]}$ | 第 $l$ 层的偏置向量 | 调节神经元被激活的难易阈值（基准线） | $(1, D_{\text{out}})$ |
| $Z^{[l]}$ | 线性加权和（Logit） | 未激活的原始计算结果 | $(N, D_{\text{out}})$ |
| $A^{[l]}$ | 激活输出（Activation） | 经过非线性激活函数后的输出特征图 | $(N, D_{\text{out}})$ |
| $\sigma(\cdot)$ | 激活函数 | 赋予网络拟合弯曲复杂函数的能力（如 ReLU、Sigmoid） | 逐元素运算 |

## 🔍 数学公式推导：从 1 个神经元到整座网络（三步走）

### 第一步：单个神经元在算什么？
单个神经元本质上就是一个**多维线性方程 + 一次非线性过滤**：
$$z = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b = \sum_{j=1}^n w_j x_j + b = \mathbf{w}^T \mathbf{x} + b$$
$$a = \sigma(z) \quad (\text{如 } \text{ReLU}(z) = \max(0, z))$$

---

### 第二步：单层有多个神经元时，如何拼成矩阵？（单样本视角）
假设输入有 **3 个特征**（如身高、体重、年龄 $\mathbf{x} = [x_1, x_2, x_3]^T$），当前层有 **2 个神经元**：
- 神经元 1 算：$z_1 = w_{11} x_1 + w_{12} x_2 + w_{13} x_3 + b_1$
- 神经元 2 算：$z_2 = w_{21} x_1 + w_{22} x_2 + w_{23} x_3 + b_2$

写成优雅的矩阵乘法形式：
$$\begin{bmatrix} z_1 \\ z_2 \end{bmatrix} = \begin{bmatrix} w_{11} & w_{12} & w_{13} \\ w_{21} & w_{22} & w_{23} \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}$$
简记为：
$$\mathbf{z}^{[l]} = W^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}$$
$$\mathbf{a}^{[l]} = \sigma(\mathbf{z}^{[l]})$$
> 📐 **维度匹配检查**：
> $(2 \times 1) = (2 \times 3) \times (3 \times 1) + (2 \times 1)$ $\implies$ **维度严格相符！**

---

### 第三步：工业界代码实战写法（Batch 批量矩阵化）
在 PyTorch / NumPy 实际工程中，我们通常一次输入 $N$ 个样本（Batch Size），每个样本作为矩阵的一**行**：
$$X \text{ 的维度为 } (N, D_{\text{in}})$$
为了让矩阵乘法顺畅进行，权重矩阵 $W$ 转置为 $(D_{\text{in}}, D_{\text{out}})$：

$$Z^{[l]} = A^{[l-1]} \cdot W^{[l]} + b^{[l]}$$
$$A^{[l]} = \sigma(Z^{[l]})$$

> 📐 **维度链条**：
> $$(N, D_{\text{out}}) = (N, D_{\text{in}}) \times (D_{\text{in}}, D_{\text{out}}) + (1, D_{\text{out}})$$
> *(注：$+ b^{[l]}$ 触发了 NumPy 的**广播机制（Broadcasting）**，自动将这一行偏置复制累加到所有 $N$ 行样本上)*。

## 🔢 真实带数字的手算范例（亲手算一遍，终身不忘）

假设我们有一个极简的双层神经网络：
- **输入数据（1 个样本，2 个特征）**：$X = \begin{bmatrix} 1.0 & 2.0 \end{bmatrix}$
- **第 1 层（2 输入 $\to$ 2 隐藏单元，ReLU 激活）**：
  $$W^{[1]} = \begin{bmatrix} 0.5 & -0.2 \\ 0.3 & 0.8 \end{bmatrix}, \quad b^{[1]} = \begin{bmatrix} 0.1 & -0.5 \end{bmatrix}$$
- **第 2 层（2 隐藏单元 $\to$ 1 输出单元，纯线性输出）**：
  $$W^{[2]} = \begin{bmatrix} 1.0 \\ -1.0 \end{bmatrix}, \quad b^{[2]} = \begin{bmatrix} 0.2 \end{bmatrix}$$

### 📝 逐步手算过程：

1. **计算第 1 层线性输出 $Z^{[1]}$**：
   $$Z^{[1]} = X \cdot W^{[1]} + b^{[1]} = \begin{bmatrix} 1.0 & 2.0 \end{bmatrix} \begin{bmatrix} 0.5 & -0.2 \\ 0.3 & 0.8 \end{bmatrix} + \begin{bmatrix} 0.1 & -0.5 \end{bmatrix}$$
   - 第 1 列：$1.0 \times 0.5 + 2.0 \times 0.3 + 0.1 = 0.5 + 0.6 + 0.1 = \mathbf{1.2}$
   - 第 2 列：$1.0 \times (-0.2) + 2.0 \times 0.8 + (-0.5) = -0.2 + 1.6 - 0.5 = \mathbf{0.9}$
   $$Z^{[1]} = \begin{bmatrix} 1.2 & 0.9 \end{bmatrix}$$

2. **计算第 1 层激活输出 $A^{[1]}$（ReLU 激活）**：
   $$A^{[1]} = \max(0, Z^{[1]}) = \max\left(0, \begin{bmatrix} 1.2 & 0.9 \end{bmatrix}\right) = \begin{bmatrix} 1.2 & 0.9 \end{bmatrix}$$
   *(若有负数则截断为 0，此处全为正数，原样保留)*。

3. **计算第 2 层（最终预测值 $\hat{y}$）**：
   $$Z^{[2]} = A^{[1]} \cdot W^{[2]} + b^{[2]} = \begin{bmatrix} 1.2 & 0.9 \end{bmatrix} \begin{bmatrix} 1.0 \\ -1.0 \end{bmatrix} + \begin{bmatrix} 0.2 \end{bmatrix}$$
   $$Z^{[2]} = (1.2 \times 1.0 + 0.9 \times (-1.0)) + 0.2 = (1.2 - 0.9) + 0.2 = \mathbf{0.5}$$
   **最终网络预测输出**：$\hat{y} = 0.5$！

4. **计算损失函数 Loss（假设真实标签 $y = 1.0$，采用均方误差 MSE）**：
   $$\text{Loss} = \frac{1}{2} (\hat{y} - y)^2 = \frac{1}{2} (0.5 - 1.0)^2 = \frac{1}{2} \times 0.25 = \mathbf{0.125}$$

## 💾 隐形关键机制：为什么训练时必须保留“前向缓存（Activation Cache）”？

在前向传播过程中，计算出的中间激活值 $A^{[0]}, A^{[1]}, Z^{[1]}$ **不能用完就扔**，训练框架（PyTorch）会把它们全部暂存在显存中。

**为什么？**
因为随后的反向传播在计算权重梯度时，依据链式法则：
$$\frac{\partial \text{Loss}}{\partial W^{[1]}} = (A^{[0]})^T \cdot dZ^{[1]}$$
公式中直接需要用到上一层的激活值 $A^{[0]} = X$！如果没有前向缓存，反向传播就无法求出梯度。

> 💡 **工程启示**：
> - **训练时**：显存大部分都被每一层的 `Activation Cache` 占满；
> - **推理/部署时（如 RKNN / 手机端）**：显式加上 `with torch.no_grad():`，PyTorch 就会彻底关闭 Cache，算完一层立刻释放，显存占用直降 70%~90%！

## 💻 最小验证代码（带详细逐行维度打印）

```python
import numpy as np

# 1. 输入数据: 2 个样本，每个样本 3 个特征 -> Shape: (2, 3)
X = np.array([
    [1.0, 2.0, 3.0],
    [0.5, 1.5, -1.0]
])

# 2. 第 1 层参数: 3 输入 -> 4 隐藏神经元
W1 = np.array([
    [ 0.1,  0.2, -0.1,  0.3],
    [-0.2,  0.1,  0.4, -0.1],
    [ 0.3, -0.3,  0.1,  0.2]
])  # Shape: (3, 4)
b1 = np.array([[0.1, 0.0, -0.2, 0.1]])  # Shape: (1, 4)

# 3. 第 2 层参数: 4 隐藏 -> 1 输出神经元
W2 = np.array([[0.5], [-0.4], [0.8], [-0.2]])  # Shape: (4, 1)
b2 = np.array([[0.05]])                         # Shape: (1, 1)

# ---- 前向传播执行 ----
# Layer 1: 线性计算 (2, 3) @ (3, 4) + (1, 4) -> (2, 4)
Z1 = np.dot(X, W1) + b1

# Layer 1: ReLU 激活 (采用 np.maximum 逐元素比较) -> (2, 4)
A1 = np.maximum(0, Z1)  # 【必须缓存 A1 供反向传播求梯度】

# Layer 2: 线性输出 (2, 4) @ (4, 1) + (1, 1) -> (2, 1)
Z2 = np.dot(A1, W2) + b2
y_pred = Z2

print("输入 X 形状:        ", X.shape)
print("隐层激活 A1 形状:   ", A1.shape)
print("预测值 y_pred 形状: ", y_pred.shape)
print("样本 1 预测得分:    ", y_pred[0, 0])
print("样本 2 预测得分:    ", y_pred[1, 0])
```

## 思考与自测
- **自测 1**：在公式 $Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}$ 中，如果上一层有 128 个神经元，当前层有 64 个神经元，权重矩阵 $W^{[l]}$ 共有多少个可学习参数？
  > *解析*：权重数量为 $64 \times 128 = 8192$ 个权重，加上 64 个偏置 $b^{[l]}$，总计 $8192 + 64 = 8256$ 个可学习参数。
- **自测 2**：如果前向传播某一层的权重全初始化为 0（$W=0$），会引发什么致命后果？
  > *解析*：对称性破坏失效（Symmetry Problem）。该层所有神经元的输出完全相同，反向传播得到的梯度也完全一致，网络退化为单个神经元。

## 关联知识
- [[反向传播]]：前向传播产出的误差与缓存是反向传播的输入。
- [[激活函数]]：前向传播中赋予网络非线性表达能力的要素。
- [[通用近似定理]]：前向多层嵌套组合造就了强大的函数拟合空间。
