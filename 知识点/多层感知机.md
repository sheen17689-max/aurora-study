# 多层感知机（MLP / Multilayer Perceptron）

> 掌握度：🟡 接触过

## 一句话直觉
如果单层感知机只能在平面上**切一条笔直的直线**（无法解决非线性的“异或 XOR”问题），那么多层感知机（MLP）就是**多把可组合弯折的折叠尺**：通过多层“线性变换（旋转拉伸）+ 非线性激活（空间弯折）”，能够拟合出任意复杂的任意高维空间决策边界。

---

## 核心要点与数学公式

### 1. 为什么必须加非线性激活函数？
假设有一个 2 层无激活函数的纯线性网络：
$$z^{[1]} = W_1 x + b_1$$
$$z^{[2]} = W_2 z^{[1]} + b_2 = W_2(W_1 x + b_1) + b_2 = (W_2 W_1)x + (W_2 b_1 + b_2) = W' x + b'$$
- **结论**：**任意多层纯线性变换的级联，在数学上完全等价于单一层线性变换**。堆叠 100 层纯线性层，其表达能力与 1 层单神经元毫无二致！
- **激活函数的本质**：给空间引入“弯折”，打破线性组合限制，赋予网络表达非线性的能力。

---

### 2. 标准 2 层 MLP 前向与反向传递矩阵方程

- **前向传播（Forward Pass）**：
  $$Z^{[1]} = X W_1^T + b_1 \quad \text{(维度: } [N, D_{in}] \times [D_{in}, D_h] + [D_h] \to [N, D_h]\text{)}$$
  $$A^{[1]} = \text{ReLU}(Z^{[1]})$$
  $$Z^{[2]} = A^{[1]} W_2^T + b_2 \quad \text{(维度: } [N, D_h] \times [D_h, D_{out}] + [D_{out}] \to [N, D_{out}]\text{)}$$
  $$\hat{Y} = \sigma(Z^{[2]})$$

- **反向传播梯度推导（Backward Pass）**：
  $$dZ^{[2]} = \hat{Y} - Y$$
  $$dW_2 = \frac{1}{N} (dZ^{[2]})^T A^{[1]}, \quad db_2 = \frac{1}{N} \sum dZ^{[2]}$$
  $$dZ^{[1]} = (dZ^{[2]} W_2) \odot \mathbb{I}(Z^{[1]} > 0) \quad \text{(ReLU 导数)}$$
  $$dW_1 = \frac{1}{N} (dZ^{[1]})^T X, \quad db_1 = \frac{1}{N} \sum dZ^{[1]}$$

## 最小验证代码（20行纯 NumPy 搞定 XOR 异或分类）

```python
import numpy as np

# 1. 异或 XOR 数据集 (非线性不可分问题)
X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([[0], [1], [1], [0]])

# 2. 初始化参数 (输入2维 -> 隐藏4维 -> 输出1维)
np.random.seed(42)
W1 = np.random.randn(2, 4) * 0.5
b1 = np.zeros((1, 4))
W2 = np.random.randn(4, 1) * 0.5
b2 = np.zeros((1, 1))

# 3. 训练 5000 轮
for _ in range(5000):
    # 前向
    h = np.maximum(0, X @ W1 + b1)            # ReLU 隐藏层
    out = 1 / (1 + np.exp(-(h @ W2 + b2)))     # Sigmoid 输出
    # 反向
    dout = out - y
    dW2, db2 = h.T @ dout, np.sum(dout, axis=0, keepdims=True)
    dh = (dout @ W2.T) * (h > 0)
    dW1, db1 = X.T @ dh, np.sum(dh, axis=0, keepdims=True)
    # 更新
    W2 -= 0.1 * dW2; b2 -= 0.1 * db2
    W1 -= 0.1 * dW1; b1 -= 0.1 * db1

print("XOR 预测结果:\n", (out > 0.5).astype(int).ravel(), "期望: [0, 1, 1, 0]")
```

## 工程与业务映射

- **PyTorch 标准定义方式**：
  ```python
  import torch.nn as nn
  mlp = nn.Sequential(
      nn.Linear(in_features=128, out_features=256),
      nn.ReLU(),
      nn.Dropout(p=0.1),
      nn.Linear(in_features=256, out_features=10)
  )
  ```
- **在现代大模型与计算机视觉中的定位**：
  - **Transformer / LLM**：每个 Attention 层后面必跟一个两层的 MLP（又称 **FFN - Feed-Forward Network**），参数量占整个大模型的三分之二，负责存储隐式世界知识与事实记忆。
  - **目标检测（YOLO / androidhub）**：Backbone 提取完特征后，最后的 Detection Head（分类分支与边界框回归分支）本质上就是小型 MLP 分类/回归器。
  - **嵌入式 / RKNN 部署**：MLP 对应 ONNX 中的 `Gemm` 或 `MatMul` 算子，在 NPU 上属于计算密度最高、加速最充分的经典算子。

## 思考与自测

- **自测 1**：在经典 MLP 中，如果把隐藏层的神经元数量 $D_h$ 设为无限大，它能拟合任何连续函数吗？
  > *解析*：可以。这就是著名的 **[[通用近似定理]]**（Universal Approximation Theorem）：只需单个包含足够多神经元的非线性隐藏层，MLP 理论上即可在任意紧致子集上以任意精度逼近任何连续非线性函数。

- **自测 2**：为什么我们在实际工程中更倾向于“增加网络深度（层数）”而不是单纯“把单一隐藏层做成无限宽”？
  > *解析*：深层网络具备**层次化特征复用**（Hierarchical Feature Reuse）能力（浅层学边缘、中层学纹理部件、深层学整体语义），能用指数级更少的参数量和计算量达到相同甚至更强的表达能力，且更容易用梯度下降有效优化。

---

## 关联知识
- [[通用近似定理]]：阐明了 MLP 隐藏层拥有万能拟合能力的数学理论基石。
- [[激活函数]]：没有非线性激活函数，MLP 会直接退化为单层线性模型。
- [[前向传播]]：MLP 的层级矩阵连乘与偏置相加流程。
- [[反向传播]]：从输出层倒推计算各层权重矩阵 $W_l$ 的梯度。
- [[损失函数]]：为 MLP 的最终输出计算任务误差。
