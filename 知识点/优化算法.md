# 优化算法（SGD → Momentum → Adam → AdamW）

> 掌握度：🟡 接触过 ｜ 所属模块：泛化、调优与评估

## 一句话直觉
优化算法是控制网络参数下山的**“智能代步工具”**：朴素 SGD 就像一个**盲人拄着拐杖走一步看一步**（在狭窄峡谷里来回撞墙）；Momentum 给它装上了**“重力惯性飞轮”**（顺着主坡道加速冲刺，冲过细小坑洼）；RMSProp 给它装上了**“自适应刹车与油门”**（颠簸方向减速，平缓方向大步迈进）；而 **Adam / AdamW** 则是集两家大成的**“智能自动驾驶越野车”**。

---

## 核心要点与数学公式

### 1. 经典优化器演进四部曲

```
朴素 SGD (小步慢走) 
   │
   ├─▶ Momentum (引入一阶动量/惯性，平滑震荡) ────┐
   │                                              ▼
   └─▶ RMSProp (引入二阶动量/自适应学习率) ──▶ Adam (动量 + 自适应，工业标配)
                                                  │
                                                  ▼
                                             AdamW (解耦权重衰减，大模型标配)
```

---

### 2. 各优化器数学方程速览

- **SGD with Momentum（一阶动量）**：
  $$v_t = \beta v_{t-1} + (1 - \beta) g_t \quad (\beta \approx 0.9)$$
  $$\theta_{t+1} = \theta_t - \eta v_t$$
  - 抑制垂直于山谷方向的高频震荡，在沿着山谷下降的平缓方向持续累加动量加速。

- **RMSProp（二阶动量 / 梯度方差自适应）**：
  $$s_t = \beta_2 s_{t-1} + (1 - \beta_2) g_t^2 \quad (\beta_2 \approx 0.999)$$
  $$\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{s_t} + \epsilon} g_t$$
  - 历史梯度平方和越大（震荡剧烈）的维度，学习率被自动压缩；历史梯度平缓的维度，步长被相对放大。

- **Adam（Adaptive Moment Estimation）**：
  结合一阶动量 $m_t$（方向）与二阶动量 $v_t$（步长），并进行偏差修正：
  $$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1 - \beta_2^t}$$
  $$\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$

- **AdamW（Decoupled Weight Decay / 大模型时代统治级优化器）**：
  - 传统 Adam 错误地将 L2 惩罚项放在梯度 $g_t$ 中进入了二阶动量归一化，导致更新量过小；
  - **AdamW 将 Weight Decay 与梯度自适应完全解耦**，直接在参数上执行衰减：
    $$\theta_{t+1} = \theta_t - \eta \cdot \lambda \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$

## 最小验证代码（NumPy 手写 Adam 核心算法）

```python
import numpy as np

# 1. 模拟参数与梯度
w = np.array([2.0, -1.0])
m = np.zeros_like(w)  # 一阶动量
v = np.zeros_like(w)  # 二阶动量

beta1, beta2, lr, eps = 0.9, 0.999, 0.01, 1e-8

# 模拟 3 个 step 的更新
for t in range(1, 4):
    grad = np.array([0.4, -0.8]) # 假定当前梯度
    
    # 更新一阶与二阶动量
    m = beta1 * m + (1 - beta1) * grad
    v = beta2 * v + (1 - beta2) * (grad ** 2)
    
    # 偏差修正
    m_hat = m / (1 - beta1 ** t)
    v_hat = v / (1 - beta2 ** t)
    
    # 参数更新
    w = w - lr * m_hat / (np.sqrt(v_hat) + eps)
    print(f"Step {t} 参数更新结果:", w.round(4))
```

## 工程与业务映射

- **PyTorch 最佳实践选型**：
  - **计算机视觉（CNN / ResNet / YOLO 训练）**：常用 **SGD + Momentum=0.937 + Weight Decay**（泛化性能往往略优于传统 Adam）；
  - **Transformer / NLP / 大语言模型（LLM）**：**必须无脑首选 `torch.optim.AdamW`**（收敛极快且稳定性无可匹敌）。

## 思考与自测

- **自测 1**：在 Adam 算法中，为什么早期的 Step（如 $t=1, 2$）必须进行偏差修正（Bias Correction）？
  > *解析*：因为 $m_0$ 和 $v_0$ 初始化为全 0。在早期（$\beta_1=0.9, \beta_2=0.999$）时，$m_1 = 0.1 g_1$、$v_1 = 0.001 g_1^2$，数值严重偏向 0（严重低估真实动量）。除以 $(1 - \beta^t)$（如 $1 - 0.999^1 = 0.001$）能将估计值无偏放大还原为真实期望。
