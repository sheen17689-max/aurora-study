# 损失函数（Loss Functions）

> 掌握度：🔵 理解 ｜ 所属模块：神经网络基础

## 一句话直觉
损失函数是模型的**“考官与成绩单”**：它定量计算模型预测值与真实标签之间的差距（即误差大小）。损失越小，说明模型表现越好；优化器顺着损失函数关于参数的负梯度方向调整权重，就是在**“根据成绩单针对性纠错”**。

---

## 一、理论基石：最大似然估计（MLE）与损失函数构建

深度学习中的经典损失函数绝非凭空捏造的经验公式，它们的深层数学根基是统计概率学中的**最大似然估计（Maximum Likelihood Estimation, MLE）**。

### 1. 似然与最大似然准则（Maximum Likelihood Principle）
- **概率 vs 似然**：
  - **概率 $P(X \mid \theta)$**：参数 $\theta$ 确定已知，求观测数据 $X$ 发生的可能性。
  - **似然 $L(\theta \mid X)$**：观测数据 $X$ 已经真实发生，评估取不同模型参数 $\theta$ 产生这组数据的可能性。
- **最大似然准则**：
  - **核心思想**：“既然当前的样本数据在现实中已经确定发生，那么使这组样本出现概率最大的参数 $\theta$，就是最合理、最可信的模型参数。”
  - 假设训练集中有 $N$ 个独立同分布（i.i.d.）的样本 $(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)$，其联合似然函数为连乘积：
    $$L(\theta) = \prod_{i=1}^{N} P(y_i \mid x_i; \theta)$$
  - 最大似然估计的目标就是寻找参数 $\hat{\theta}_{\text{MLE}}$ 使得联合似然最大：
    $$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \prod_{i=1}^{N} P(y_i \mid x_i; \theta)$$

---

### 2. 为什么需要最大化对数似然（Log-Likelihood）？
直接对连乘式 $\prod_{i=1}^N P$ 进行优化在数学与工程上面临极大困难，因此通常对似然函数取自然对数 $\ln$，转化为**对数似然**：
$$\ln L(\theta) = \sum_{i=1}^{N} \ln P(y_i \mid x_i; \theta)$$

取自然对数的核心原因：
1. **防止数值下溢（Numerical Underflow）**：
   每个样本的条件概率 $P(y_i \mid x_i; \theta) \in [0, 1]$。当样本量 $N$ 较大时，成千上万个小于 1 的小数连续相乘会以指数级速度趋向于 0，导致计算机浮点数发生下溢溢出。取对数后，**连乘转化为连加**，数值计算极其稳定。
2. **简化微积分求导**：
   在微积分中，和的导数等于导数的和（$\frac{d}{d\theta}\sum f_i = \sum \frac{d}{d\theta}f_i$），而积的求导法则展开极为冗长复杂，转化为加法后梯度计算极其清晰高效。
3. **极值点位置严格不变**：
   因为对数函数 $f(x) = \ln(x)$ 在定义域 $(0, +\infty)$ 上是**严格单调递增**的，它不改变极值点的位置，即：
   $$\arg\max_\theta L(\theta) = \arg\max_\theta \ln L(\theta)$$

---

### 3. 为什么需要最小化负对数似然（Negative Log-Likelihood, NLL）？
在机器学习与数学优化体系中，几乎所有的标准优化算法（如梯度下降法 Gradient Descent）默认都被设计为**寻找目标函数的极小值（Minimization）**：
$$\text{标准优化范式：} \min_{\theta} \mathcal{L}(\theta)$$

为了将“求最大值”与“梯度下降求极小值”无缝对接，只需在对数似然前加一个负号，即得到**负对数似然（Negative Log-Likelihood, NLL）**：
$$\arg\max_\theta \ln L(\theta) \iff \arg\min_\theta \big[ -\ln L(\theta) \big]$$

因此，负对数似然函数定义为：
$$\mathcal{L}_{\text{NLL}}(\theta) = -\sum_{i=1}^{N} \ln P(y_i \mid x_i; \theta)$$

在机器学习工程实践中，通常除以样本量 $N$ 以消除 Batch 大小对损失尺度的影响（经验风险最小化）：
$$\text{Loss}(\theta) = -\frac{1}{N} \sum_{i=1}^{N} \ln P(y_i \mid x_i; \theta)$$
**结论：深度学习模型训练中“最小化损失函数”，其本质完全等价于统计学中的“最大似然估计”。**

---

### 4. 构建损失函数的通用方法论（从分布先验到损失函数）
损失函数的设计，本质上是**对目标数据标签 $y$ 的条件概率分布 $P(y \mid x)$ 做出先验假设**。构建任意自定义损失函数遵循通用的 4 步法：
```
1. 审视任务与物理规律 ──> 假设条件概率分布 P(y|x; θ)
             ↓
2. 根据独立同分布(i.i.d.) ──> 建立联合似然函数 L(θ) = ∏ P
             ↓
3. 取对数并加负号 ──> 得到负对数似然 NLL = -∑ ln P
             ↓
4. 忽略与参数 θ 无关的常数项 ──> 得到最终紧凑的损失函数 Loss
```

| 任务类型 | 假设的数据分布先验 | 负对数似然推导 (NLL) | 导出的经典损失函数 |
| :--- | :--- | :--- | :--- |
| **标准连续回归** | **高斯正态分布** $\mathcal{N}(\mu, \sigma^2)$ | $-\ln\Big(\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(y-\hat{y})^2}{2\sigma^2}}\Big) \propto (y-\hat{y})^2$ | **MSE Loss (均方误差 / L2)** |
| **鲁棒连续回归** | **拉普拉斯分布** $\text{Laplace}(\mu, b)$ | $-\ln\Big(\frac{1}{2b}e^{-\frac{\|y-\hat{y}\|}{b}}\Big) \propto \|y-\hat{y}\|$ | **MAE Loss (平均绝对误差 / L1)** |
| **二分类 / 多标签** | **伯努利分布** (0-1分布) | $-\ln\big(\hat{y}^y (1-\hat{y})^{1-y}\big)$ | **BCE Loss (二分类交叉熵)** |
| **单标签多分类** | **类别分布** (Categorical) | $-\ln\big(\prod_{c=1}^C \hat{y}_c^{y_c}\big) = -\sum_{c=1}^C y_c \ln \hat{y}_c$ | **Cross-Entropy Loss (多分类交叉熵)** |

## 二、核心损失函数推导与特性

### 1. 回归任务常用损失

- **高斯分布先验 $\implies$ 均方误差（MSE, Mean Squared Error / L2 Loss）**：
  - **分布假设**：假设模型预测值与真实值之间的误差服从均值为 0、方差为 $\sigma^2$ 的正态分布，即 $y \sim \mathcal{N}(\hat{y}, \sigma^2)$：
    $$P(y \mid x; \theta) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(y - \hat{y})^2}{2\sigma^2}\right)$$
  - **公式推导**：
    $$-\ln P(y \mid x; \theta) = \ln(\sqrt{2\pi}\sigma) + \frac{1}{2\sigma^2}(y - \hat{y})^2$$
    忽略与参数 $\theta$ 无关的常数 $\ln(\sqrt{2\pi}\sigma)$ 与固定常数系数 $\frac{1}{2\sigma^2}$，即得到标准均方误差：
    $$L_{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$
  - **导数**：$\frac{\partial L}{\partial \hat{y}_i} = \frac{2}{N}(\hat{y}_i - y_i)$
  - **特点**：对离群点（Outliers）非常敏感（误差平方级惩罚放大）；但在极值点附近梯度平滑，易于平稳收敛。

- **拉普拉斯分布先验 $\implies$ 平均绝对误差（MAE / L1 Loss）**：
  - **分布假设**：假设误差服从具有重尾特性的拉普拉斯分布 $\epsilon \sim \text{Laplace}(0, b)$：
    $$P(y \mid x; \theta) = \frac{1}{2b} \exp\left(-\frac{|y - \hat{y}|}{b}\right)$$
  - **公式推导**：取负对数似然直接得到绝对值形式：
    $$L_{MAE} = \frac{1}{N} \sum_{i=1}^{N} |y_i - \hat{y}_i|$$
  - **特点**：相比高斯分布的平方级发散，拉普拉斯分布为线性衰减，对离群点更稳健（Robust）；但导数在 0 点处不可导且非零区域梯度恒为 $\pm 1$，在最优解附近容易震荡。

- **Smooth L1 Loss（Huber Loss）**：在误差较小时使用平滑的 $L2$（防震荡），误差较大时切换为线性的 $L1$（抗离群值），常用于目标检测边界框回归（如 YOLO / Faster R-CNN）。

---

### 2. 分类任务常用损失

- **伯努利分布先验 $\implies$ 二分类交叉熵（Binary Cross-Entropy / BCE Loss）**：
  - **分布假设**：二分类任务真实标签 $y \in \{0, 1\}$，模型预测样本为正类的概率为 $\hat{y} = \sigma(z) \in (0, 1)$。单样本概率质量函数为：
    $$P(y \mid x; \theta) = \hat{y}^y (1 - \hat{y})^{1 - y}$$
  - **公式推导**：直接取负对数似然：
    $$-\ln P(y \mid x; \theta) = -\Big[ y \ln(\hat{y}) + (1 - y) \ln(1 - \hat{y}) \Big]$$
    扩展到整个数据集求均值，即为标准 BCE 损失：
    $$L_{BCE} = -\frac{1}{N} \sum_{i=1}^{N} \Big[ y_i \ln(\hat{y}_i) + (1 - y_i) \ln(1 - \hat{y}_i) \Big]$$

- **类别分布先验 $\implies$ 多分类交叉熵（Categorical Cross-Entropy Loss）**：
  - **分布假设**：样本共有 $C$ 个互斥类别，真实标签采用 One-hot 编码向量 $y = [y_1, y_2, \dots, y_C]$，网络输出经 Softmax 得到预测概率分布 $\hat{y}$。单样本概率公式为：
    $$P(y \mid x; \theta) = \prod_{c=1}^{C} \hat{y}_c^{y_c}$$
  - **公式推导**：取负对数似然：
    $$L_{CE} = -\sum_{c=1}^{C} y_c \ln(\hat{y}_c) = -\ln(\hat{y}_{\text{target}})$$
  - **优雅求导性质**：将 Softmax 与 CrossEntropy 结合后，损失对原始 Logits $z_c$ 的偏导极其优雅简洁：
    $$\frac{\partial L}{\partial z_c} = \hat{y}_c - y_c$$
    即**模型预测概率分布与真实 One-hot 标签的直接差值**！这也是现代深度学习分类网络标配该组合的核心原因。

## 最小验证代码（NumPy 验证 NLL 与 Cross-Entropy 等价性）

```python
import numpy as np

# 1. 模拟网络输出 Logits 与真实标签 (真实标签为类别 0)
logits = np.array([2.5, 1.0, 0.1])
target_idx = 0
y_true_onehot = np.array([1.0, 0.0, 0.0])

# 2. Softmax 概率计算 (减去最大值防止指数上溢)
exp_z = np.exp(logits - np.max(logits))
probs = exp_z / np.sum(exp_z)

# 3. 双重视角计算: 交叉熵公式 vs 真实类别的负对数似然 (NLL)
ce_loss = -np.sum(y_true_onehot * np.log(probs + 1e-12))
nll_loss = -np.log(probs[target_idx] + 1e-12)

# 4. 对 Logits 的反向解析梯度: y_hat - y
grad_z = probs - y_true_onehot

print(f"预测概率分布: {probs.round(3)}")
print(f"交叉熵 Loss: {ce_loss:.4f} | 负对数似然 NLL: {nll_loss:.4f} (两者严格数学等价)")
print(f"对 Logits 的梯度 (dLoss/dz): {grad_z.round(3)}")
```

## 工程与业务映射

- **PyTorch 底层解耦：`nn.CrossEntropyLoss` vs `nn.NLLLoss`**：
  - 在 PyTorch 中，`nn.CrossEntropyLoss()` 内部完整封装了 **`nn.LogSoftmax()` + `nn.NLLLoss()`** 两步。
  - 这意味着如果网络末端手写了 `nn.LogSoftmax()`，后续必须接 `nn.NLLLoss()`；如果网络直接输出原始 Logits，必须使用 `nn.CrossEntropyLoss()`。**切勿手写 `nn.Softmax()` 后再传给 `nn.CrossEntropyLoss()`**，否则会导致两次 Softmax 压扁概率分布，梯度极小致使网络瘫痪。
- **二分类数值下溢防护**：
  - 二分类或多标签分类中，推荐始终使用 `nn.BCEWithLogitsLoss()` 代替 `nn.Sigmoid()` + `nn.BCELoss()`。前者底层应用了 Log-Sum-Exp 数值稳定技巧，能彻底避免极端 Logit 导致概率为 0 时的 `log(0)` NaN 崩溃。
- **目标检测多任务复合损失（YOLO 系列）**：
  - 最终的 Total Loss 是多个不同概率先验分支的加权综合：
    $$\text{Loss}_{\text{total}} = \lambda_{\text{box}} \cdot L_{\text{CIoU}} + \lambda_{\text{cls}} \cdot L_{\text{BCE}} + \lambda_{\text{dfl}} \cdot L_{\text{DFL}}$$
    其中分类分支用伯努利 NLL（BCE），框回归分支使用几何重叠与回归损失。

## 思考与自测

- **自测 1**：为什么在机器学习优化中，我们要把“最大化对数似然”转化为“最小化负对数似然（NLL）”？
  > *解析*：因为以梯度下降法（SGD/Adam）为核心的数值优化体系在数学上标准定义为**寻找函数的全局/局部极小值**。通过添加负号，原本使得数据生成概率最大的“最大化目标”，自然转换成了通过负梯度更新参数的“最小化损失目标”（$\arg\max \ln L \iff \arg\min [-\ln L]$），保证了算法接口和理论框架的统一。

- **自测 2**：分类任务为什么不用 MSE（均方误差），而必须用基于最大似然推导的交叉熵（CE）？
  > *解析*：若在分类任务中采用 MSE 配合 Sigmoid/Softmax，当模型错得非常离谱时（如真实为 1，预测概率接近 0），激活函数的饱和区导数 $\sigma'(z) \approx 0$，导致 MSE 梯度趋近于 0（发生严重“梯度消失”，越错反而越学不动）；而通过最大似然推导的交叉熵与 Softmax/Sigmoid 结合后，导数恰好化简为 $\hat{y} - y$，预测错得越离谱，梯度惩罚越大，能以最快速度将参数纠偏。

- **自测 3**：如果要针对一种特殊任务（比如预测服务器每秒接收的请求次数，为离散正整数计数）设计损失函数，该如何应用最大似然准则构建？
  > *解析*：① 首先分析数据物理规律：计数数据通常服从**泊松分布（Poisson Distribution）** $P(y \mid \lambda) = \frac{\lambda^y e^{-\lambda}}{y!}$；② 让神经网络输出泊松分布的率参数 $\hat{\lambda} = \exp(f_\theta(x)) > 0$；③ 对泊松分布取负对数似然：$-\ln P = \hat{\lambda} - y \ln \hat{\lambda} + \ln(y!)$；④ 略去不含模型参数的常数项 $\ln(y!)$，最终得到的损失函数即为泊松回归损失：$\mathcal{L} = \hat{\lambda} - y \ln \hat{\lambda}$（这也正是 PyTorch 中的 `nn.PoissonNLLLoss`）。

## 关联知识
- [[概率基础]]：高斯分布、伯努利分布与极大似然估计的数学源头。
- [[线性回归]]：均方误差 MSE 的最大似然推导与解析闭式解。
- [[前向传播]]：前向计算输出 Logits 并交由损失函数打分。
- [[反向传播]]：以损失函数的导数为起点启动链式法则反向求偏导。
- [[激活函数]]：Softmax 与 Sigmoid 常作为损失函数的直接输入映射。
- [[梯度下降]]：利用损失函数的负梯度调整全网参数。
