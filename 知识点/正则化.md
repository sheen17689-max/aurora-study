# 正则化（L1 / L2 权重衰减与 Dropout）

> 掌握度：🟡 接触过 ｜ 所属模块：泛化、调优与评估

## 一句话直觉
正则化是模型的**“紧箍咒与防呆机制”**：如果模型参数自由度过大，它就会像一个死记硬背的学生把训练集里每一个偶然噪声甚至答题纸上的污渍都强行记住（过拟合）；正则化通过**“给权重过大施加罚款（L2/L1）”**或**“考试前随机遮挡部分神经元强迫全队独立协作（Dropout）”**，迫使网络只学习普适性强、鲁棒性高的关键规律。

---

## 核心要点与数学公式

### 1. L2 正则化（Ridge / 权重衰减 Weight Decay）
在原始损失函数后追加所有权重的平方和惩罚项：
$$L_{\text{total}}(\theta) = L_{\text{data}}(\theta) + \frac{\lambda}{2N} \sum_{l} \|W^{[l]}\|_F^2$$
- **反向梯度与权重更新（Weight Decay 本质）**：
  $$\nabla_W L_{\text{total}} = \nabla_W L_{\text{data}} + \lambda W$$
  $$W_{t+1} = W_t - \eta \left( \nabla_W L_{\text{data}} + \lambda W_t \right) = (1 - \eta \lambda) W_t - \eta \nabla_W L_{\text{data}}$$
  - 每次更新前，权重都会被预先**乘以一个略小于 1 的因子 $(1 - \eta \lambda)$ 进行缩减衰减**！避免任何单一权重变得畸大。

---

### 2. L1 正则化（Lasso / 稀疏性 Sparsity）
$$L_{\text{total}}(\theta) = L_{\text{data}}(\theta) + \frac{\lambda}{N} \sum |W|$$
- **特点**：次梯度在 0 处恒为 $\pm \lambda$，会将不重要的特征权重**直接驱动精准压缩为 0**，产生天然的稀疏矩阵，可用于特征选择与模型剪枝。

---

### 3. Dropout（随机失活 / 隐式集成学习）
- **训练阶段**：以概率 $p$ 随机将神经元输出置 0，并采用 **Inverted Dropout** 进行缩放补偿：
  $$\tilde{a} = \frac{a \odot \text{Bernoulli}(1-p)}{1 - p}$$
- **推理阶段**：**直接关闭 Dropout**（`model.eval()`），原样输出，无需做任何缩放计算！
- **本质机理**：打破神经元之间的“共适应性（Co-adaptation）”，相当于在训练过程中动态采样了 $2^N$ 个子网络进行集成。

## 最小验证代码（NumPy 手写 Inverted Dropout 与 L2 梯度）

```python
import numpy as np

# 1. 模拟隐藏层激活值 [Batch=2, Dim=4]
a = np.array([[1.2, 3.4, 0.8, 2.1],
              [0.5, 2.0, 1.5, 0.2]])

# 2. Inverted Dropout 掩码生成 (失活概率 drop_rate=0.5, 保留率 keep_prob=0.5)
drop_rate = 0.5
keep_prob = 1.0 - drop_rate
mask = (np.random.rand(*a.shape) < keep_prob).astype(float)

# 训练阶段输出 (除以 keep_prob 保持期望一致)
a_train = (a * mask) / keep_prob
print("Dropout 训练阶段输出:\n", a_train)
print(f"原始均值: {a.mean():.3f} | Dropout后期望均值: {a_train.mean():.3f}")

# 3. L2 权重衰减 (Weight Decay) 计算
W = np.array([2.0, -1.5, 0.8])
lr, wd = 0.01, 0.1
grad_raw = np.array([0.5, -0.2, 0.1])

# 更新权重: W = (1 - lr * wd) * W - lr * grad_raw
W_new = (1 - lr * wd) * W - lr * grad_raw
print("L2 权重衰减后 W:", W_new.round(4))
```

## 工程与业务映射

- **PyTorch 训练/推理模式切换核心**：
  - `model.train()`：开启 Dropout 随机丢弃，开启 BatchNorm 的 Running 统计量更新；
  - `model.eval()`：**彻底关闭 Dropout**，固定 BatchNorm 参数，保证推理结果确定且高效。
- **目标检测与 RKNN 嵌入式部署**：
  - RKNN / NPU 模型转换时，**Dropout 算子会被直接彻底剥离移除**（因为推理阶段无用），不耗费任何 NPU 芯片算力。

## 思考与自测

- **自测 1**：在现代以 Batch Normalization 和 Residual Connection 为主的深层卷积网络（如 ResNet）中，为什么很少在卷积层之间加 Dropout？
  > *解析*：卷积层特征图具有极强的空间局部相关性（相邻像素语义极其相似），随机置零单个像素并不能阻断特征协同（相邻像素能轻易还原信息）；且 BatchNorm 本身带有 Batch 维度的轻微随机噪声，具有天然的正则化效果。因此现代 CNN 多采用 DropPath / Stochastic Depth，或仅在全连接层使用 Dropout。
