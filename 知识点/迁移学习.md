# 迁移学习（Transfer Learning & Fine-Tuning）

> 掌握度：🟡 接触过 ｜ 所属模块：卷积神经网络（CNN）

## 一句话直觉
迁移学习就像**“让学过十年绘画的高手去转行学画特定树叶”**：从零随机初始化训练一个视觉模型需要数百万张图片和数周算力；迁移学习直接借用在海量通用数据（如 ImageNet / COCO）上预训练好的成熟骨干网络（Backbone，已掌握边缘、光影、纹理特征），只需要极少量的自定义数据进行“微调（Fine-Tuning）”，就能在几个小时内达到极高的任务精度。

---

## 核心要点与数学公式

### 1. 迁移学习三大常用策略

```
策略 1：特征提取器 (Feature Extractor)   ──▶ 冻结 Backbone 权重，仅训练末端新分类 Head
策略 2：全局微调 (Full Fine-Tuning)     ──▶ 载入预训练权重，用极小学习率全网联合微调
策略 3：分层差异化微调 (Discriminative LR) ──▶ 浅层设极小学习率 (1e-5)，深层设大学习率 (1e-3)
```

| 场景条件 | 推荐策略 | 操作方法 |
| :--- | :--- | :--- |
| **数据量极小，任务与原任务相似** | 仅微调线性分类头 | 锁定主干参数 `requires_grad = False`，仅更新替换后的分类全连接层 |
| **数据量充足，任务与原任务相似** | 全网络微调 | 载入预训练权重，设置较小学习率（如 $\eta = 10^{-4}$）训练全网 |
| **数据量极小，任务与原任务差异大** | 提取浅层特征 + 简单分类器 | 截取前几层浅层卷积特征，后接 SVM 或小 MLP |

## 最小验证代码（PyTorch 冻结主干微调新分类头）

```python
import torch
import torch.nn as nn
import torchvision.models as models

# 1. 载入官方预训练的 ResNet-18 权重
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

# 2. 冻结所有 Backbone 参数 (不参与反向传播计算与更新)
for param in model.parameters():
    param.requires_grad = False

# 3. 替换最后的线性分类头 (原始 1000 类 -> 目标任务 2 类)
num_features = model.fc.in_features
model.fc = nn.Linear(num_features, 2) # 新加入的层 requires_grad 默认 True

# 4. 优化器仅更新未冻结的分类头参数
optimizer = torch.optim.Adam(filter(lambda p: p.requires_grad, model.parameters()), lr=1e-3)

# 验证可训练参数量对比
total_params = sum(p.numel() for p in model.parameters())
trainable_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
print(f"总参数量: {total_params:,} | 当前微调参数量: {trainable_params:,} (仅占 {trainable_params/total_params:.1%})")
```

## 思考与自测

- **自测 1**：在微调下游任务时，为什么通常不能使用过大的初始学习率（如 $\eta = 0.1$）？
  > *解析*：过大的学习率产生剧烈的梯度更新，会瞬间“洗掉”预训练模型在海量数据上千锤百炼学得的通用特征表征（灾难性遗忘 Catastrophic Forgetting）。微调的核心思想是小步轻调。
