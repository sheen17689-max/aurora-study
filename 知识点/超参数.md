# 超参数（Hyperparameters）

> 掌握度：🟡 接触过 ｜ 所属模块：神经网络基础与闭环 › 深度神经网络

## 一句话直觉
超参数是算法工程师为神经网络设定的**“成长规则与外部环境”**：**参数（$W, b$）**是模型自己通过做题（反向传播）总结出的内部知识；而**超参数（学习率、网络深度、Batch Size、Dropout）**则是老师为它定制的学习方法、作息时间与课桌大小——**模型自己学不会这些规则，必须由外部人为指定与调试**。

---

## 核心要点与数学公式

### 1. 参数（Parameters） vs 超参数（Hyperparameters）

| 对比维度 | 模型参数（Model Parameters） | 超参数（Hyperparameters） |
| :--- | :--- | :--- |
| **定义** | 模型内部通过学习自动优化的权重和偏置 | 人为在模型训练前指定的结构与训练配置 |
| **获取方式** | 训练时通过**反向传播与梯度下降自动更新** | 由**算法工程师手动设定**或通过 HPO 自动搜索算法寻优 |
| **典型示例** | 权重矩阵 $W$、偏置向量 $\mathbf{b}$、BN 的 $\gamma, \beta$ | 学习率 $\eta$、Batch Size、网络层数 $L$、Dropout 率 $p$ |
| **目标** | 拟合训练数据的特征与规律 | 引导与控制训练过程，决定模型的容量、收敛速度与泛化能力 |

---

### 2. 深度神经网络中三大类超参数

```
                          ┌─ 架构超参数 (网络结构): 深度 L、宽度/隐藏维度 D、卷积核大小、激活函数
                          │
深度学习超参数 (Hyperparameters) ┼─ 优化与训练超参数 (学习过程): 学习率 η、Batch Size、Epochs、优化器及动量参数
                          │
                          └─ 正则化超参数 (泛化防过拟合): 权重衰减 λ、Dropout 概率 p、梯度裁剪阈值
```

#### ① 网络架构超参数（定义模型表达容量）
- **深度（Depth）与宽度（Width）**：隐藏层层数 $L$ 与各层神经元数/特征图通道数（Channels）。
- **卷积与池化配置（CNN）**：卷积核尺寸（Kernel Size）、步长（Stride）、填充（Padding）。
- **注意力与结构维度（Transformer）**：注意力头数（Number of Heads）、隐藏层维度 $d_{model}$、前馈层（FFN）中间维度。
- **激活函数选择**：ReLU、GELU、Swish、LeakyReLU 等。

#### ② 优化与训练超参数（控制梯度更新节奏）
- **学习率（Learning Rate, $\eta$）**：**最核心、影响最剧烈的超参数**。
  $$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \cdot \nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}_t)$$
  - $\eta$ 过大：Loss 震荡发散甚至报 `NaN`；
  - $\eta$ 过小：收敛极其缓慢，容易困在局部鞍点。
- **批量大小（Batch Size）**：单次前向/反向传播计算梯度的样本数。
  - 小 Batch：噪声多，具有隐式正则化效果，更易跳出局部极小值，但硬件并行利用率低；
  - 大 Batch：梯度估计稳定、并行效率高，但需配合线性缩放学习率（Linear Scaling Rule: $\eta \propto \text{Batch Size}$）。
- **迭代轮数（Epochs）与步数（Steps/Iterations）**：遍历整个训练集的轮次。
- **优化器内部参数**：
  - Adam / AdamW：一阶动量衰减 $\beta_1$（默认 0.9）、二阶矩衰减 $\beta_2$（默认 0.999）、数值稳定项 $\epsilon$（$10^{-8}$）。
- **学习率调度器（LR Scheduler）**：Warmup 步数、余弦退火周期 $T_{max}$、阶梯衰减因子 $\gamma$。

#### ③ 正则化与泛化超参数（抑制过拟合）
- **权重衰减系数 / L2 正则化（Weight Decay, $\lambda$）**：
  $$\mathcal{L}_{total} = \mathcal{L}_{data} + \frac{\lambda}{2} \|\mathbf{W}\|_2^2$$
- **Dropout 概率（$p$）**：训练时随机失活神经元的比例（常见 $0.1 \sim 0.5$）。
- **梯度裁剪阈值（Gradient Clipping Norm, $c$）**：防止深层网络或 RNN 梯度爆炸。

---

### 3. 超参数调试优先级与法则

- **调优优先级金字塔**：
  $$\text{学习率 } \eta \gg \text{学习率调度策略 (Warmup/Cosine)} > \text{Batch Size / 优化器} > \text{网络深度/宽度} > \text{Weight Decay / Dropout}$$
- **对数尺度搜索法则（Log Scale）**：
  学习率与权重衰减具有跨数量级敏感性，必须在指数空间采样（如 $\eta \in [10^{-4}, 10^{-1}]$），绝不可线性均匀抽样。

## 最小验证代码（<20行纯 NumPy：学习率的三种命运）

```python
import numpy as np

# 在最简单的损失碗 f(w) = w² 上做梯度下降，只看学习率 η 这一个超参数
def gd(lr, w=8.0, steps=12):
    traj = []
    for _ in range(steps):
        w = w - lr * 2 * w      # 梯度 df/dw = 2w，更新步长完全由 lr 决定
        traj.append(w)
    return np.round(traj, 3)

print("lr=0.01 太小(爬不动):  ", gd(0.01))   # 12 步后还剩 6.28，几乎没动
print("lr=0.25 合适(每步减半):", gd(0.25))   # 12 步收敛到 0.002
print("lr=1.10 太大(震荡发散):", gd(1.10))   # 左右横跳，12 步爆炸到 ±71.3
```

> 同一模型、同一数据、同一起点，**只改一个超参数就从「爬不动」到「秒收敛」再到「直接炸」**——这就是为什么学习率排在调优优先级金字塔顶端。

## 工程配置模板（PyTorch 核心超参数集中管理）

```python
import torch
import torch.nn as nn
import torch.optim as optim

# ==================== 1. 定义超参数字典 ====================
HYPERPARAMS = {
    # 架构超参数
    "input_dim": 128,
    "hidden_dim": 256,
    "num_layers": 3,
    "dropout_rate": 0.2,
    # 优化与训练超参数
    "batch_size": 64,
    "learning_rate": 1e-3,
    "weight_decay": 1e-4,
    "epochs": 10,
    "grad_clip": 1.0,
}

# ==================== 2. 应用超参数构建网络 ====================
class MLP(nn.Module):
    def __init__(self, hp):
        super().__init__()
        layers = []
        in_d = hp["input_dim"]
        for _ in range(hp["num_layers"]):
            layers.extend([
                nn.Linear(in_d, hp["hidden_dim"]),
                nn.ReLU(),
                nn.Dropout(hp["dropout_rate"])
            ])
            in_d = hp["hidden_dim"]
        layers.append(nn.Linear(in_d, 1))
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x)

model = MLP(HYPERPARAMS)

# ==================== 3. 优化器与损失函数绑定超参数 ====================
criterion = nn.MSELoss()
optimizer = optim.AdamW(
    model.parameters(),
    lr=HYPERPARAMS["learning_rate"],
    weight_decay=HYPERPARAMS["weight_decay"]
)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=HYPERPARAMS["epochs"])

print("模型参数总量 (Trainable Params):", sum(p.numel() for p in model.parameters() if p.requires_grad))
print("超参数配置:", HYPERPARAMS)
```

## 工程与业务映射

- **YOLO 训练超参数配置文件（`hyp.yaml`）**：
  YOLOv8 中通过单独的 YAML 文件集中管理 20+ 个超参数（如 `lr0=0.01`, `lrf=0.01`, `momentum=0.937`, `box=7.5`, `cls=0.5` 等），便于多卡集群复现与版本管理。
- **自动化调优工具（Optuna / Ray Tune）**：
  在工程落地中，算法工程师通常定义好超参数搜索空间，利用 Optuna 配合剪枝算法（Pruning / Hyperband）自动化寻找最优超参数组合。

## 思考与自测

- **自测 1**：Batch Size 从 32 增大到 256 时，如果不调整学习率，模型训练通常会出现什么问题？为什么？
  > *解析*：Batch Size 扩大 8 倍时，每个 Epoch 内参数更新步数减少了 8 倍。如果不按比例调大学习率（遵循线性缩放法则 $\eta \propto \text{Batch Size}$），模型在相同 Epoch 下参数更新总距离不足，收敛速度会显著变慢且容易陷入次优解。
- **自测 2**：BatchNorm 中的均值（$\mu$）和方差（$\sigma^2$）是模型参数还是超参数？
  > *解析*：既不是可导的模型参数（不通过梯度更新），也不是训练前固定的人工超参数，而是**运行时统计量（Running Statistics / Buffer）**，由前向传播时根据各 Batch 样本动态滑动平均计算得到。

## 关联知识
- [[深度神经网络]]：DNN 整体架构中的各层堆叠深度、宽度与激活函数均属于架构超参数。
- [[组合神经网络]]：网络深度 $L$ 与神经元宽度 $K$ 决定了空间折叠的区域上限 $\mathcal{O}(K^L)$。
- [[梯度下降]]：学习率 $\eta$ 是控制梯度步长的核心超参数。
- [[超参数搜索策略]]：网格搜索、随机搜索与贝叶斯优化等自动化寻优方法。
- [[学习率调度策略]]：控制学习率随训练周期动态退火的策略超参数。
