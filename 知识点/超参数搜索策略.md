# 超参数搜索策略（Hyperparameter Optimization / HPO）

> 掌握度：🟡 接触过 ｜ 所属模块：泛化、调优与评估

## 一句话直觉
超参数搜索是模型调优的**“黄金配方寻宝图”**：参数（权重 $W$）由反向传播自己学，而超参数（学习率、Batch Size、权重衰减、网络层数）必须由工程师指定。网格搜索像**地毯式无脑踩雷**，随机搜索像**全面撒网抽样**，而贝叶斯优化（Optuna / Ray Tune）则像**自带记忆的地质勘探专家**（根据已知矿点预测下一个最高概率出金矿的坐标）。

## 核心要点与数学公式

### 1. 三大主流超参数搜索方法对比

```
【网格搜索 (Grid)】         【随机搜索 (Random)】         【贝叶斯优化 (Bayesian / Optuna)】
  ○──○──○──○                 ○   ○    ○                    ○ (高潜先验)
  ○──○──○──○               ○    ○   ○                        ↗
  ○──○──○──○                 ○    ○    ○               ○ ──▶ ○ (根据历史高分预测)
  (低效/维度灾难)             (高维空间效率远超网格)         (高效/以最小试验次数逼近最优)
```

| 方法 | 搜索机理 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **网格搜索 (Grid Search)** | 在预设的离散超参数网格中穷举遍历 | 逻辑简单，不会遗漏设定组合 | 参数越多计算量呈指数级爆炸（维度灾难） |
| **随机搜索 (Random Search)** | 在连续分布空间中随机均匀抽样 | 在非重要参数维度上探索度极高，显著优于网格搜索 | 盲目抽样，无法利用历史实验的经验反馈 |
| **贝叶斯优化 (Bayesian Opt)** | 利用高斯过程（GP）或 TPE 建模目标函数后验分布，利用采集函数（EI）选择下一个最具潜力的参数 | 样本效率极高，能在极少试验次数下找到全局最优解 | 依赖算法框架库（如 Optuna） |

---

### 2. 学习率对数尺度搜索法则（Logarithmic Scale）
- ❌ **错误做法**：在 $[0.0001, 0.1]$ 上进行线性均匀抽样（$0.0001, 0.02, 0.04, 0.06, 0.08, 0.1$）$\implies$ 90% 的算力被浪费在 $0.01 \sim 0.1$ 的危险过大区间！
- ✅ **正确做法**：**在对数尺度（Log Scale）上均匀采样**：
  $$r \sim \mathcal{U}(-4, -1) \implies \eta = 10^r \quad (10^{-4}, 10^{-3}, 10^{-2}, 10^{-1})$$

## 最小验证代码（Optuna 自动化调优示例）

```python
import numpy as np

# 模拟一个带噪声的目标评价函数 (寻找最佳学习率与权重衰减)
def mock_train_eval(lr, weight_decay):
    # 假想最优解在 lr=1e-3, weight_decay=1e-4
    val_loss = (np.log10(lr) - (-3))**2 + (np.log10(weight_decay) - (-4))**2 + np.random.randn()*0.05
    return val_loss

# 1. 简易随机对数采样搜索
best_loss, best_params = float('inf'), {}
for _ in range(20):
    lr = 10 ** np.random.uniform(-4, -1)
    wd = 10 ** np.random.uniform(-5, -2)
    score = mock_train_eval(lr, wd)
    if score < best_loss:
        best_loss, best_params = score, {'lr': lr, 'weight_decay': wd}

print(f"最佳验证 Loss: {best_loss:.4f}")
print(f"最佳超参数组合: lr={best_params['lr']:.5f}, wd={best_params['weight_decay']:.5f}")
```

## 思考与自测

- **自测 1**：在资源有限的情况下，通常按什么优先级对深度学习超参数进行调优？
  > *解析*：
  > 1. **第一优先级（最敏感致命）**：学习率 $\eta$（及 Warmup/调度策略）；
  > 2. **第二优先级**：优化器动量参数（$\beta_1, \beta_2$）、Batch Size、权重衰减（Weight Decay）；
  > 3. **第三优先级**：网络层数、隐藏层维度、Dropout 率、数据增强强度。
