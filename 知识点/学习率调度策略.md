# 学习率调度策略（Learning Rate Scheduling）

> 掌握度：🟡 接触过 ｜ 所属模块：泛化、调优与评估

## 一句话直觉
学习率调度是训练过程中的**“油门换挡器”**：起步阶段（Warmup）踩小油门防止参数剧烈甩尾脱轨，巡航阶段踩大油门快速冲向终点，进站收尾阶段（Cosine Annealing）轻点刹车逐步微调、平稳停靠在全局最优深谷的最低点。

---

## 核心要点与数学公式

### 1. 为什么不能全程使用固定学习率？
- **固定大学习率**：早期冲刺快，但后期会在最优解两壁剧烈震荡跳跃，永远无法落入谷底最低点；
- **固定小学习率**：前期爬行极其缓慢，容易被困在浅层局部极小值或鞍点中，训练耗时数倍。

---

### 2. 现代深度学习三大主流调度策略

```
学习率 η
  ▲          ┌─────────────────┐ (余弦衰减 Cosine Decay)
  │         /                   \
  │        /                     \
  │       / (Warmup 热身)          \
  │      /                          \
  └─────┴────────────────────────────┴────────▶ Epochs
```

- **1. 学习率热身（Linear Warmup）**：
  - **公式**：在前 $T_{warmup}$ 轮中，学习率从 0 线性爬升到基准学习率 $\eta_{max}$：
    $$\eta_t = \frac{t}{T_{warmup}} \eta_{max}$$
  - **机理**：网络刚开始随机初始化时，梯度极不稳定，较小的学习率可以避免初期的坏梯度将网络摧毁。

- **2. 余弦退火调度（Cosine Annealing LR）**：
  - **公式**：
    $$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max} - \eta_{min})\left( 1 + \cos\left( \frac{t}{T_{max}}\pi \right) \right)$$
  - **特点**：曲线极其平滑优雅，前期平缓、中期快速下降、后期极平缓微调，是计算机视觉（YOLO）和大语言模型训练的标准首选。

- **3. 步阶衰减（StepLR / MultiStepLR）**：
  - 每训练固定的 Epoch（如每 30 轮），学习率乘以衰减因子 $\gamma = 0.1$。

- **4. 自适应监测衰减（ReduceLROnPlateau）**：
  - 当验证集指标连续 $N$ 个 Epoch 停止提升时，自动将学习率打折缩减。

## 最小验证代码（PyTorch 调度器联动）

```python
import torch
import torch.nn as nn
from torch.optim.lr_scheduler import CosineAnnealingLR

# 1. 模拟简单线性模型与优化器
model = nn.Linear(10, 2)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

# 2. 绑定余弦退火调度器 (总周期 100 轮, 最低学习率 1e-4)
scheduler = CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-4)

# 3. 模拟 5 个 Epoch 的学习率衰减跟踪
lrs = []
for epoch in range(5):
    lrs.append(optimizer.param_groups[0]['lr'])
    optimizer.step()
    scheduler.step()

print("前 5 轮学习率衰减轨迹:", [round(x, 5) for x in lrs])
```

## 思考与自测

- **自测 1**：为什么在超大 Batch Size 训练（如 Batch Size=4096）时，Linear Warmup 几乎成为强制必选项？
  > *解析*：根据线性缩放准则（Linear Scaling Rule），Batch Size 扩大 $k$ 倍时，基准学习率通常也必须等比例扩大 $k$ 倍。如果训练第 1 轮就直接使用这个巨大的初始学习率，模型在随机起点处会立即发生梯度爆炸，导致 Loss 飙升为 NaN。Warmup 让参数先进入相对平稳的参数流形区域后再施加大步长。
