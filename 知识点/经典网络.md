# 经典卷积网络演进（LeNet → AlexNet → VGG → ResNet）

> 掌握度：🟡 接触过 ｜ 所属模块：卷积神经网络（CNN）

## 一句话直觉
经典视觉网络的演进就是**“人类征服深度的史诗”**：从手写数字的开山鼻祖（LeNet-5），到点燃深度学习革命火种的开山重器（AlexNet），再到整齐美观的模块化堆叠（VGG），最后到用一条**“残差捷径（Skip Connection）”彻底打破网络深度诅咒的封神之作（ResNet）**。

---

## 核心要点与数学公式

### 1. 经典架构进化树

```
LeNet-5 (1998) ──▶ AlexNet (2012) ──▶ VGG-16 (2014) ──▶ ResNet (2015)
(开创 CNN 架构)    (ReLU/Dropout/GPU)  (全 3x3 堆叠)       (残差恒等映射，深度突破 1000 层)
```

| 网络 | 年份 | 关键突破与设计创新 | 痛点 / 历史意义 |
| :--- | :--- | :--- | :--- |
| **LeNet-5** | 1998 | `Conv -> Pool -> FC` 经典组合，手写数字识别 | 激活函数用 Sigmoid/Tanh，难以加深 |
| **AlexNet** | 2012 | 引入 **ReLU**、**Dropout**、多 GPU 并行、数据增强 | 斩获 ImageNet 冠军，开启现代深度学习时代 |
| **VGG** | 2014 | 全部采用连续的小 $3\times3$ 卷积核与 $2\times2$ 池化 | 结构规整易迁移，但末端全连接层参数极其庞大（1.38 亿） |
| **ResNet** | 2015 | **残差结构（Residual Block / 跨层短路连接）** | 彻底解决深层网络的“退化问题（Degradation）”，横扫各大顶会 |

---

### 2. ResNet 残差连接的数学奇迹

传统网络拟合目标映射 $\mathcal{H}(x)$；何恺明团队将其改写为**拟合残差映射 $\mathcal{F}(x) = \mathcal{H}(x) - x$**：
$$y = \mathcal{F}(x, \{W_i\}) + x$$

- **反向梯度求导（核心推导）**：
  $$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \frac{\partial y}{\partial x} = \frac{\partial L}{\partial y} \left( \frac{\partial \mathcal{F}}{\partial x} + 1 \right) = \frac{\partial L}{\partial y} \frac{\partial \mathcal{F}}{\partial x} + \frac{\partial L}{\partial y}$$
- **奇迹所在**：反向传播时，即使中间权重 $\frac{\partial \mathcal{F}}{\partial x}$ 极小甚至为 0，右边的常数项 **$+1$** 能够保证上层梯度**毫无衰减阻碍地直接直达最浅层输入**！

## 最小验证代码（PyTorch 手写极简 ResNet 残差块）

```python
import torch
import torch.nn as nn

class BasicResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, kernel_size=3, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(channels, channels, kernel_size=3, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x):
        identity = x                     # 1. 缓存捷径输入
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += identity                  # 2. 残差相加 (Skip Connection)
        out = self.relu(out)             # 3. 激活输出
        return out

# 测试前向传播
block = BasicResidualBlock(channels=64)
x = torch.randn(4, 64, 32, 32)
print("输入形状:", x.shape, "-> 残差输出形状:", block(x).shape)
```

## 工程与业务映射

- **Backbone（特征提取主干）地位**：
  - ResNet-18 / ResNet-50 是目标检测（YOLO）、图像分割（UNet）和嵌入式安防摄像头中最通用、量化最友好、精度最扎实的工业级主干网络。
- **RKNN 硬件部署**：
  - 残差相加算子（`Add`）在 NPU 芯片上完全支持多分支零拷贝硬件对齐。

## 思考与自测

- **自测 1**：网络退化问题（Degradation）和过拟合（Overfitting）是一回事吗？
  > *解析*：完全不是一回事。过拟合表现为“训练集误差很低、测试集误差很高”；而退化问题表现为“56层网络的训练集误差居然比 20层网络还要高（连训练集都学不会）”。ResNet 残差连接彻底消除了退化问题，使超千层网络能够轻松收敛。
