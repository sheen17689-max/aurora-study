# 统计量与离散度（方差、标准差与 MAD）

> 掌握度：🟡 接触过 ｜ 所属模块：数学与数据地基 ｜ 更新：2026-08-25

## 一句话直觉
如果说“均值与中位数”告诉你数据的**中心位置在哪里**，那么“方差、标准差与 MAD”则告诉你**数据的波动有多剧烈、风险有多大、预测有多不可靠**：
- **均值是“平均水深”，离散度是“水下的深坑高度”**：只看平均水深 1 米去过河会淹死，必须知道水深的离散波动范围；
- **射击稳定性比喻**：两个射手平均都是 9 环，标准差小的选手枪枪命中 9 环（极稳），标准差大的选手一会儿 10 环一会儿 3 环（不可控）。

## 核心要点与数学公式

### 1. 深度剖析：方差、标准差与 MAD 到底代表什么物理意义？

```
                         ┌── 方差 (Variance, σ²) ──────▶ 物理意义: 信号波动总能量 / 不确定性总量 (单位被平方)
                         │
三大离散度量本质 ────────┼── 标准差 (Std, σ) ───────────▶ 物理意义: 数据的典型浮动半径 (与原数据同量纲, 3σ准则)
                         │
                         └── 绝对中位差 (MAD, 鲁棒版) ──▶ 物理意义: 正常主干数据的抗噪波动半宽 (50%崩溃点防弹衣)
```

| 统计指标 | 本质代表的物理意义 | 直觉比喻 | 为什么用它？（优点与致命弱点） |
| :--- | :--- | :--- | :--- |
| **方差 ($\sigma^2$)** | **数据波动能量 / 不确定性的总量** | 空间中所有点到中心点的**欧氏距离平方和** | **优点**：处处平滑可导，数学推导极其优美；<br>**弱点**：单位被平方了（物理直觉失真），且对极端离群点有**“平方级过度惩罚”**。 |
| **标准差 ($\sigma$ 或 $s$)** | **数据的“典型浮动范围 / 离散半径”** | 恢复与原始数据同等尺度的**真实波动范围** | **优点**：量纲与原数据一致（如温度 $\pm 3^\circ\text{C}$）；$3\sigma$ 准则圈定了 99.7% 的正常数据分布区间。 |
| **平均绝对偏差 ($\text{MAD}_{mean}$)** | **数据点到均值的“平均直线步行距离”** | 曼哈顿距离（$L_1$ 范数）的平均 | 相比方差，它以**线性比例**对待偏差，不会过度放大离群点。 |
| **绝对中位差 ($\text{MAD}_{median}$)** | **典型正常样本的“核心离散半径 / 抗噪护甲”** | 剔除极端值后的**稳态波动半宽** | **真正意义**：**崩溃点高达 50%**。只要坏数据不超过一半，它就能极其真实地反映主力数据的波动范围，是脏数据清洗的“防弹衣”。 |

### 2. 为什么深度学习（AI）工程师必须深刻理解这三者？

1. **为什么权重初始化（Xavier / He）追求“方差守恒”？**
   - 如果每一层前向传播后特征的方差越来越大（$\sigma^2 \to \infty$），信号就会发生**数值溢出 / 梯度爆炸**；
   - 如果每一层方差越来越小（$\sigma^2 \to 0$），信号就会衰减为常数（**特征坍塌 / 梯度消失**）；
   - **方差在深度网络中代表特征信号的“信息量与动态范围”！**
2. **为什么 Batch Normalization（BN）要除以标准差 $\sqrt{\sigma^2 + \epsilon}$？**
   - 强行把每一层神经元的激活分布拉回到 $\mu=0, \sigma=1$ 的标准正态区间，消除“内部协变量偏移”，让梯度在平坦的地形上高速奔跑。
3. **为什么视觉目标检测（YOLO）回归损失要用 Smooth L1 而不是 MSE？**
   - MSE（基于方差思路）对于极难标注样本或脏数据会产生天价梯度，容易引发训练震荡；
   - Smooth L1（结合了 MAD 的 $L_1$ 思路）限制了最大误差梯度为常数 1，获得了极致的鲁棒稳定性！

## 🔢 真实带数字的手算范例（以包含离群点的数据为例）

假设我们有 5 个样本数据：$$\mathbf{X} = [2, 4, 4, 4, 16]$$
*(注意：其中 $16$ 是一个明显的离群异常点)*。

### ① 方差（Variance）计算 3 步走：
1. **求样本均值 $\bar{x}$**：
   $$\bar{x} = \frac{2 + 4 + 4 + 4 + 16}{5} = \frac{30}{5} = \mathbf{6}$$
2. **算每个数减去均值的差（离差），并求平方**：
   - $(2 - 6)^2 = (-4)^2 = 16$
   - $(4 - 6)^2 = (-2)^2 = 4$
   - $(4 - 6)^2 = (-2)^2 = 4$
   - $(4 - 6)^2 = (-2)^2 = 4$
   - $(16 - 6)^2 = (10)^2 = \mathbf{100}$ *(离群点 16 被平方放大为 100！)*
3. **求平方和的平均值**：
   - 平方和 $= 16 + 4 + 4 + 4 + 100 = 128$
   - **总体方差 $\sigma^2$** $= \frac{128}{5} = \mathbf{25.6}$
   - **样本方差 $s^2$（除以 $N-1=4$，Bessel 无偏修正）** $= \frac{128}{5 - 1} = \frac{128}{4} = \mathbf{32.0}$

---

### ② 标准差（Standard Deviation）计算：
直接对方差开平方根（单位恢复为和 $X$ 一样）：
- **总体标准差**：$\sigma = \sqrt{25.6} \approx \mathbf{5.06}$
- **样本标准差**：$s = \sqrt{32.0} \approx \mathbf{5.66}$

---

### ③ MAD（两种不同计算方式）手算：

#### 方式 A：平均绝对偏差（Mean Absolute Deviation）
- 算每个数与均值（$\bar{x}=6$）的**绝对距离**：
  $$|2-6|=4, \quad |4-6|=2, \quad |4-6|=2, \quad |4-6|=2, \quad |16-6|=10$$
- 求这 5 个绝对距离的平均值：
  $$\text{MAD}_{mean} = \frac{4 + 2 + 2 + 2 + 10}{5} = \frac{20}{5} = \mathbf{4.0}$$

#### 方式 B：绝对中位差（Median Absolute Deviation，鲁棒抗噪神器）
- **第 1 步：先找原数据的中位数**
  把数据从小到大排序：$[2, 4, \mathbf{4}, 4, 16] \implies \text{Median}(\mathbf{X}) = \mathbf{4}$
- **第 2 步：计算每个数与中位数（4）的绝对差**
  $$|2-4|=2, \quad |4-4|=0, \quad |4-4|=0, \quad |4-4|=0, \quad |16-4|=12$$
  得到绝对差列表：$[2, 0, 0, 0, 12]$
- **第 3 步：把这组绝对差排序，再求它们的中位数**
  排序后：$[0, 0, \mathbf{0}, 2, 12]$
  中间那个数是第 3 个数：
  $$\text{MAD}_{median} = \mathbf{0}$$
- **💡 直觉结论**：
  因为大部分数据都聚集在 4，哪怕那个 16 变成 10000，$\text{MAD}_{median}$ 依然稳稳等于 0，**完全不受任何极端异常值的破坏！**

## 最小验证代码（NumPy 对比与打印）

```python
import numpy as np

# 样本数据
x = np.array([2.0, 4.0, 4.0, 4.0, 16.0])

# 1. 均值与中位数
mean_val = np.mean(x)
med_val = np.median(x)

# 2. 总体方差与样本方差
var_pop = np.var(x)         # ddof=0
var_sample = np.var(x, ddof=1) # ddof=1 (Bessel 修正)

# 3. 总体标准差与样本标准差
std_pop = np.std(x)
std_sample = np.std(x, ddof=1)

# 4. 平均绝对离差 (Mean Absolute Deviation)
mad_mean = np.mean(np.abs(x - mean_val))

# 5. 绝对中位差 (Median Absolute Deviation)
mad_median = np.median(np.abs(x - med_val))

print(f"数据: {x}")
print(f"均值: {mean_val:.2f} | 中位数: {med_val:.2f}")
print(f"总体方差: {var_pop:.2f} | 样本方差: {var_sample:.2f}")
print(f"总体标准差: {std_pop:.2f} | 样本标准差: {std_sample:.2f}")
print(f"平均绝对离差 MAD(mean): {mad_mean:.2f}")
print(f"绝对中位差 MAD(median): {mad_median:.2f}")
```

## 工程与业务映射

- **Batch Normalization（批归一化）**：
  深度网络前向传播时，每层利用 mini-batch 的**均值 $\mu_B$ 和方差 $\sigma_B^2$** 对输入进行缩放校准：
  $$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$
- **工业数据清洗：Hampel 滤波（3-MAD 准则）**：
  在清洗摄像头坏点或标注脏数据时，不采用脆弱的 $3\sigma$（易被脏数据拉偏），而改用 **$3 \times (1.4826 \times \text{MAD})$** 进行过滤，精准剔除异常值。
- **损失函数的 L1 vs L2 权衡**：
  MSE Loss（基于方差思想）惩罚大误差，对离群点极敏感；MAE Loss（基于 MAD 思想）梯度恒定，抗噪性能强。

## 思考与自测

- **自测 1**：为什么样本方差公式要除以 $N-1$ 而不是 $N$？
  > *解析*：因为样本均值 $\bar{x}$ 是从当前这批样本估计出来的，样本数据点天然更靠近自己算出来的 $\bar{x}$，导致 $\sum (x_i - \bar{x})^2$ 总是低估总体真实方差。除以 $N-1$（失去 1 个自由度）补偿了这种偏倚，使其成为对总体方差的**无偏估计**。
- **自测 2**：在正态分布下，为什么绝对中位差常乘以 $1.4826$？
  > *解析*：对于标准正态分布，中位数绝对偏差恰好为 $0.6745 \cdot \sigma$。因此 $\hat{\sigma} = \frac{\text{MAD}}{0.6745} \approx 1.4826 \cdot \text{MAD}$，以此在正态分布下作为标准差的无偏鲁棒估计。
