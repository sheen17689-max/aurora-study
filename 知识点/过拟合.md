# 过拟合（Overfitting）

> 掌握度：🟡 接触过 ｜ 所属：三、泛化与调优 ｜ 更新：2026-08-14

## 一句话直觉
就像一个学生在考前死记硬背了真题的标点符号和题目序号（甚至背错了印刷错误），导致平时做刷过的题得 100 分，但一遇到新考卷（未知测试数据）就完全不会变通、大面积考砸。

## 核心要点与数学公式
- **泛化误差与过拟合判定**：
  $$E_{test} \gg E_{train}$$
  训练集损失 $L_{train} \to 0$，但验证集损失 $L_{val}$ 先降后升，出现严重分叉。
- **高方差（High Variance）**：模型复杂度过高，过度贴合有限数据中的随机噪声。
- **系统性治理药方**：
  1. **数据扩增（Data Augmentation）**：增加样本多样性（翻转、裁剪、色彩抖动）；
  2. **L2 正则化（Weight Decay）**：惩罚过大权重，使权重更平滑分散：
     $$L_{reg} = L_0 + \frac{\lambda}{2m} \sum w_i^2$$
  3. **Dropout**：训练时随机“失活”一部分神经元，破坏神经元间的共适应性（Co-adaptation）；
  4. **早停（Early Stopping）**：在 $L_{val}$ 达到最低拐点时提前终止训练；
  5. **简化模型容量**：减少网络层数或隐藏单元通道数。

## 最小验证代码（<20行纯 NumPy L2 权重衰减）
```python
import numpy as np

# 模拟带 L2 正则化的单步权重更新: w = w - lr * (grad + lambda * w)
w = np.array([2.5, -3.0, 1.8])
grad = np.array([0.1, -0.2, 0.05])
lr, lambda_l2 = 0.01, 0.1

# L2 相当于在每次更新前让权重先乘以 (1 - lr * lambda_l2) 衰减
w_updated = w - lr * (grad + lambda_l2 * w)
print(f"原权重: {w}")
print(f"L2更新后（幅值被温和压制）: {np.round(w_updated, 4)}")
```

## 工程与业务映射
- **YOLO 目标检测中的抗过拟合**：
  - YOLO 训练中大量使用 Mosaic 数据增强、MixUp，并在最后一阶段关闭 Mosaic（如最后 10 个 epoch），这是典型的工程化抗过拟合与微调策略。
  - YOLO 默认开启 `weight_decay=0.0005`。
- **姿态识别业务（androidhub）**：
  - 当训练样本只覆盖了特定机位或光照时，移动端上线后识别率下降，本质就是过拟合了特定采集环境。

## 思考与自测
- **自测 1**：Dropout 在训练阶段和推理（Inference）阶段的表现有什么不同？
  > *解析*：训练时以概率 $p$ 随机关闭节点并按 $1/(1-p)$ 缩放激活值（Inverted Dropout）；而在推理部署时，必须关闭 Dropout，所有神经元全量参与前向计算以保证确定性输出。
- **自测 2**：在损失曲线上，如何一眼看出模型发生了过拟合？
  > *解析*：Train Loss 一直稳步下降，而 Val Loss 降到某个极小值后开始调头向上翘起，两者间隙（Gap）不断拉大。

## 关联知识
- [[梯度下降]]：学习率过高或步数过长常加剧过拟合。
- [[反向传播]]：L2 正则化在反向传播时为权重梯度贡献了一项 $\lambda w$。
