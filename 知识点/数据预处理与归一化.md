# 数据预处理与归一化（Data Preprocessing & Normalization）

> 掌握度：🟡 接触过 ｜ 所属模块：数学与数据地基

## 一句话直觉
输入数据就像**“不同币种的资金”**（有的特征是 0～1 的比率，有的是 0～100000 的金额）。如果不换算成统一的基准单位（归一化），梯度下降就会像走在一条极其狭长的峡谷里反复横跳、寸步难行；归一化就像**“把狭长椭圆峡谷压成正圆形的对称碗状盆地”**，让梯度能够笔直、快速地滑向全局最优底点。

---

## 核心要点与数学公式

### 1. 为什么必须做特征归一化（Normalizing Inputs）？

- **未归一化的几何灾难**：
  若输入 $x_1 \in [0, 1]$ 而 $x_2 \in [0, 1000]$，损失函数对 $w_2$ 的微小变化极其敏感，而对 $w_1$ 的变化极其迟钝。导致损失等高线呈现**极度扁平的细长椭圆**：
  - 学习率设大 $\implies$ 在短轴（$w_2$ 方向）剧烈震荡发散；
  - 学习率设小 $\implies$ 在长轴（$w_1$ 方向）龟速爬行，训练极慢。
- **归一化后的良态曲面**：
  各维度尺度一致后，等高线变为**对称的同心圆/超球体**，优化器可以用较大的学习率直冲中心。

---

### 2. 两大主流归一化方法

- **Z-Score 标准化（Standardization / 零均值单位方差）**：
  $$\mu = \frac{1}{N}\sum_{i=1}^N x_i, \quad \sigma^2 = \frac{1}{N}\sum_{i=1}^N (x_i - \mu)^2$$
  $$\tilde{x} = \frac{x - \mu}{\sigma + \epsilon}$$
  - **特点**：处理后均值为 0，标准差为 1。适用于大多数深度学习模型（如图像 ImageNet 预处理：`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`）。

- **Min-Max 归一化（Min-Max Scaling / 区间缩放）**：
  $$\tilde{x} = \frac{x - x_{min}}{x_{max} - x_{min}}$$
  - **特点**：将数据线性压缩至 $[0, 1]$ 或 $[-1, 1]$。对离群点（Outliers）极为敏感。

## 最小验证代码（NumPy 模拟等高线改善）

```python
import numpy as np

# 1. 模拟原始不平衡特征 (特征1: 0~1, 特征2: 0~10000)
raw_data = np.array([
    [0.1, 1200.0],
    [0.8, 8500.0],
    [0.4, 4300.0],
    [0.9, 9800.0]
])

# 2. Z-Score 零均值标准化
mean = np.mean(raw_data, axis=0)
std = np.std(raw_data, axis=0)

norm_data = (raw_data - mean) / (std + 1e-8)

print("原始均值与方差:", mean.round(1), std.round(1))
print("归一化后均值 (期望全为0):", np.mean(norm_data, axis=0).round(4))
print("归一化后方差 (期望全为1):", np.std(norm_data, axis=0).round(4))
```

## 工程与业务映射

- **🚨 致命工程陷阱：数据泄露（Data Leakage）**：
  - **黄金铁律**：计算均值 $\mu$ 和方差 $\sigma$ 时，**只能且必须仅使用训练集（Training Set）统计！**
  - 测试集与验证集必须使用从训练集学到的 $\mu_{train}$ 和 $\sigma_{train}$ 进行转换，绝不能在全量数据（包含测试集）上统一计算均值方差，否则会导致测试集信息泄露给模型。
- **图像预处理流水线（Torchvision / Albumentations / androidhub）**：
  - 标准流程：`Image (0~255) -> ToTensor() (缩放到 0~1) -> Normalize(mean, std)`。

## 思考与自测

- **自测 1**：如果输入数据已经做了 Z-Score 归一化，为什么在网络深层依然需要使用 Batch Normalization（批归一化）？
  > *解析*：输入归一化只能保证第 1 层的输入服从良态分布。随着网络加深，多层权重乘加后，深层神经元的输入分布会再次发生偏移（内部协变量偏移 Internal Covariate Shift），因此需要在深层网络内部插入 Batch Normalization 持续校准中间特征分布。
