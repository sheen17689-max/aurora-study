# 反向传播（Backpropagation）

> 掌握度：⚪ 未学

## 一句话直觉
如果最终成品出现了误差（Loss），反向传播就像**公司内部的项目复盘问责链**：从最终交付的产品出发，依据微积分链式法则逆向倒推，计算出流水线上每一道工序、每一个参数对总误差该承担多少“责任”（偏导数梯度）。

## 核心要点与数学公式
- **链式法则（Chain Rule）**：
  若 $z = f(y)$，$y = g(x)$，则：
  $$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y} \cdot \frac{\partial y}{\partial x}$$
- **计算图与矩阵形式（单层线性 + 激活）**：
  前向传播：$Z = WX + b \implies A = \sigma(Z) \implies L(A, Y)$
  反向传播：
  $$\frac{\partial L}{\partial Z} = dZ = dA \odot \sigma'(Z)$$
  $$\frac{\partial L}{\partial W} = \frac{1}{m} dZ \cdot X^T, \quad \frac{\partial L}{\partial b} = \frac{1}{m} \sum dZ$$
- **动态规划思想**：从后向前缓存中间梯度，避免了前向自动求导导致的指数级重复计算。
- **痛点风险**：Sigmoid/Tanh 的导数最大值 $\le 0.25$，深层连乘极易导致**梯度消失**；故现代网络多采用 ReLU 激活。

## 最小验证代码（<20行纯 NumPy 单神经元）
```python
import numpy as np

# 数据: x=2.0, 真实值 y=1.0, 初始权重 w=0.5
x, y_true, w = 2.0, 1.0, 0.5

# 前向传播 (MSE Loss)
y_pred = w * x
loss = 0.5 * (y_pred - y_true) ** 2

# 反向传播 (链式求导: dLoss/dw = dLoss/dy_pred * dy_pred/dw)
dloss_dypred = y_pred - y_true     # (1.0 - 1.0) = 0.0 或 (w*x - y)
dypred_dw = x                      # x = 2.0
grad_w = dloss_dypred * dypred_dw  # 最终梯度

print(f"y_pred: {y_pred:.2f} | Loss: {loss:.4f} | dLoss/dw: {grad_w:.4f}")
```

## 工程与业务映射
- **PyTorch `loss.backward()`**：调用该方法即是在动态计算图上执行一次完整的反向传播，将每个 `requires_grad=True` 张量的 `.grad` 字段填满。
- **RKNN / 嵌入式前向推理**：量化部署在 NPU 芯片上时，**反向传播的代码和梯度变量全被裁剪丢弃**，只保留前向算子计算图以极致压缩内存。

## 思考与自测
- **自测 1**：为什么反向传播必须从输出层向输入层反推，而不是从输入层向前推？
  > *解析*：深度网络中输出通常是标量 Loss，输入是成千上万维的特征。从标量输出往回反向传播（Reverse-mode autodiff），只需 1 次反向遍历即可求出 Loss 对所有亿级参数的梯度；若从前向后推（Forward-mode），则需要对每个输入特征分别遍历一次，计算成本不可承受。
- **自测 2**：网络发生梯度消失时，最靠近输入层还是最靠近输出层的参数最先“学不动”？
  > *解析*：最靠近输入层的参数。因为链式法则乘积链条最长，每一层小于 1 的导数因子连乘导致回传到浅层时梯度几乎衰减为 0。

## 关联知识
- [[梯度下降]]：消费反向传播求得的 `grad_w` 更新权重。
- [[过拟合]]：权重衰减（L2 正则）会在反向传播梯度中额外追加一行 $\lambda W$。
