# 参数初始化（Parameter Initialization）

> 掌握度：🟡 接触过 ｜ 所属模块：神经网络基础

## 一句话直觉
参数初始化是网络的**“起跑线姿态”**：深度学习就像多级火箭升空，如果初始姿态偏差一丁点（初始方差过大或过小），经过几十层矩阵乘法连乘后，信号就会呈指数级**“暴增炸飞（梯度爆炸）”**或**“衰减熄火（梯度消失）”**。优秀的初始化方法能保证信号在穿越 100 层网络时，每一层的方差都始终保持稳定。

---

## 核心要点与数学公式

### 1. 为什么不能全 0 初始化？
- **对称性破坏失效（Symmetry Breaking）**：
  若同一层权重全为 0，前向输出完全一致，反向梯度完全对称，所有神经元永远步调一致做相同更新，导致多神经元退化为单个神经元。

### 2. 为什么不能用简单的标准正态分布 $\mathcal{N}(0, 1)$？
若输入维数 $D_{in} = 512$，经过线性变换 $z = \sum_{i=1}^{512} W_i X_i$，其输出方差为：
$$\text{Var}(z) = D_{in} \cdot \text{Var}(W) \cdot \text{Var}(X) = 512 \cdot 1 \cdot 1 = 512$$
经过 10 层连乘后，方差膨胀为 $512^{10} \approx 10^{27}$，瞬间造成数值溢出（NaN）！

---

### 3. 现代深度学习两大黄金初始化标准

- **Xavier (Glorot) 初始化 —— 适用于 Tanh / Sigmoid / Linear**：
  目标是让输入方差与输出方差保持一致（$\text{Var}(A^{[l]}) = \text{Var}(A^{[l-1]})$）：
  $$W \sim \mathcal{N}\left(0, \frac{2}{D_{in} + D_{out}}\right) \quad \text{或} \quad W \sim \mathcal{U}\left(-\sqrt{\frac{6}{D_{in} + D_{out}}}, \sqrt{\frac{6}{D_{in} + D_{out}}}\right)$$

- **He (Kaiming) 初始化 —— 适用于 ReLU / LeakyReLU**：
  考虑到 ReLU 会将一半的负数截断置零（方差天然折损一半），何恺明团队证明初始方差必须额外翻倍：
  $$W \sim \mathcal{N}\left(0, \frac{2}{D_{in}}\right) \quad \text{或} \quad W \sim \mathcal{U}\left(-\sqrt{\frac{6}{D_{in}}}, \sqrt{\frac{6}{D_{in}}}\right)$$

## 最小验证代码（NumPy 模拟 10 层前向方差稳定性）

```python
import numpy as np

# 1. 模拟 1000 个 512 维输入样本
X = np.random.randn(1000, 512)
Din, Dout = 512, 512

# 2. 对比普通正态分布 vs He 初始化 在 10 层 ReLU 下的方差表现
def test_init(scale_factor):
    h = X
    for _ in range(10):
        W = np.random.randn(Din, Dout) * scale_factor
        h = np.maximum(0, h @ W)
    return np.var(h)

print("标准正态初始化 (std=1.0) 10层后方差:", test_init(1.0)) # 极大爆炸
print("极小正态初始化 (std=0.01) 10层后方差:", test_init(0.01)) # 趋近于0 消失
print("He (Kaiming) 初始化 (std=sqrt(2/Din)) 10层后方差:", test_init(np.sqrt(2.0 / Din)).round(4)) # 稳定在 1.0 附近！
```

## 工程与业务映射

- **PyTorch 默认初始化行为**：
  - `nn.Linear` 默认使用 Kaiming 均匀分布初始化；
  - `nn.Conv2d` 默认使用 Kaiming 均匀分布初始化；
  - 可以通过 `torch.nn.init.kaiming_normal_(layer.weight, mode='fan_in', nonlinearity='relu')` 自定义重置。
- **偏置 $b$ 的初始化法则**：
  - 绝大多数情况下，偏置 $b$ 直接初始化为 **0**（`nn.init.constant_(layer.bias, 0)`）即可，不会产生对称性问题。

## 思考与自测

- **自测 1**：如果网络激活函数采用 ReLU，但错误地使用了 Xavier 初始化，训练早期容易出现什么现象？
  > *解析*：Xavier 的方差是 $\frac{1}{D_{in}}$，而 ReLU 需要 $\frac{2}{D_{in}}$。使用 Xavier 会导致信号随着层数加深方差以 $0.5^L$ 的速度指数衰减，深层神经元逐渐进入静默状态，早期收敛显著变慢。

## 关联知识
- [[激活函数]]：激活函数的几何特性决定了必须匹配何种初始化方法（ReLU 匹配 He，Tanh 匹配 Xavier）。
- [[多层感知机]]：MLP 各层权重的初始化直接决定前向与反向传播的数值稳定性。
- [[梯度下降]]：良态的初始化为梯度下降提供了平滑好走的初始起跑点。
