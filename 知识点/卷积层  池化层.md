# 卷积层 / 池化层

> 掌握度：🟡 接触过 ｜ 所属：四、卷积神经网络（CNN） ｜ 更新：2026-08-14

## 一句话直觉
卷积层就像**“手持特征放大镜（滑窗）在整张图片上扫描找规律”**：它利用**局部连接**和**权值共享**，不论猫在图片左上角还是右下角，都能用同一组卷积核检测出它的胡须和耳朵（平移不变性）；而池化层就像**“拍低分辨率缩略图”**，在保留最强特征的同时把分辨率压缩一半，大幅减少计算量并扩大感受野。

## 核心要点与数学公式
- **输出特征图尺寸公式**：
  $$H_{out} = \left\lfloor \frac{H_{in} - K + 2P}{S} \right\rfloor + 1$$
- **权值共享与局部感受野**：参数量从全连接的数亿级暴降到几千，彻底解决视觉图像过拟合。
- **最大池化（Max Pooling）**：提取最显著特征；全局平均池化（GAP）替代末端全连接。

## 最小验证代码（<20行纯 NumPy）
```python
import numpy as np
image = np.array([[0,0,0],[10,10,10],[0,0,0]], dtype=float)
kernel = np.array([[1,2,1],[0,0,0],[-1,-2,-1]], dtype=float) # Sobel 边缘核
out = np.sum(image * kernel)
print("Sobel 边缘响应:", out)
```

## 工程与业务映射
- **androidhub / YOLO / RKNN**：NPU 硬件通过 `im2col + GEMM` 高效执行卷积；与 BN 算子无损融合。

## 思考与自测
- **自测 1**：为什么两个堆叠的 $3\times3$ 卷积优于单个 $5\times5$ 卷积？
  > *解析*：感受野完全相同（均为 5），但参数量减少 28%（$18 < 25$），且多了一层非线性激活函数，特征表达能力更强。
