# 概率基础（常用分布与期望方差）

> 掌握度：🟡 接触过 ｜ 所属模块：数学与数据地基

## 一句话直觉
如果微积分教我们如何“确定性地优化”，概率论则教我们如何**“在充满噪声的世界里科学地量化不确定性”**：神经网络本质上是一个条件概率分布估计器 $P(Y \mid X; \theta)$，而分类任务的交叉熵损失，本质就是概率论中的**极大似然估计（Maximum Likelihood Estimation, MLE）**。

---

## 核心要点与数学公式

### 1. 期望与方差（Expectation & Variance）
- **期望（重心/均值）**：
  $$\mathbb{E}[X] = \sum_i x_i P(x_i) \quad \text{或} \quad \mathbb{E}[X] = \int x p(x) dx$$
- **方差与标准差（离散波动程度）**：
  $$\text{Var}(X) = \mathbb{E}[(X - \mathbb{E}[X])^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2, \quad \sigma = \sqrt{\text{Var}(X)}$$
  - 协方差 $\text{Cov}(X, Y) = \mathbb{E}[(X - \mu_X)(Y - \mu_Y)]$ 衡量两变量相关性。

---

### 2. 深度学习四大核心分布

| 概率分布 | 表达式 / 形状 | 深度学习典型应用场景 |
| :--- | :--- | :--- |
| **伯努利分布 (0-1分布)** | $P(x=1)=p, P(x=0)=1-p$ | 二分类任务标签建模、Dropout 掩码生成 |
| **分类分布 (Categorical)** | $P(x=k)=p_k, \sum p_k = 1$ | 多分类任务输出（Softmax 概率分布） |
| **高斯正态分布 $\mathcal{N}(\mu, \sigma^2)$** | $p(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | 权重初始化（Xavier/He）、VAE 隐空间重参数化、扩散模型加噪 |
| **均匀分布 $\mathcal{U}(a, b)$** | $p(x) = \frac{1}{b - a}$ | 数据增强随机裁剪/旋转旋转角度采样、均匀权重初始化 |

---

### 3. 极大似然估计（MLE）与损失函数的统一
- 假设样本独立同分布，最大化似然函数等价于**最小化负对数似然（Negative Log-Likelihood, NLL）**：
  $$\theta^* = \arg\max_\theta \sum_{i=1}^N \log P(y_i \mid x_i; \theta) = \arg\min_\theta \sum_{i=1}^N \Big( -\log P(y_i \mid x_i; \theta) \Big)$$
- **当假设误差服从高斯分布时 $\implies$ 导出 MSE 均方误差损失**；
- **当假设输出服从伯努利/分类分布时 $\implies$ 导出 交叉熵 Cross-Entropy 损失**！

## 最小验证代码（NumPy 模拟伯努利采样与高斯生成）

```python
import numpy as np

# 1. 模拟 Dropout 掩码生成 (保留概率 p=0.8 的伯努利分布)
p = 0.8
dropout_mask = (np.random.rand(4, 5) < p).astype(float) / p
print("Inverted Dropout 掩码:\n", dropout_mask)

# 2. 验证高斯分布的经验均值与方差
samples = np.random.normal(loc=0.0, scale=2.0, size=100000)
print(f"经验均值: {np.mean(samples):.4f} (理论 0.0) | 经验标准差: {np.std(samples):.4f} (理论 2.0)")
```

## 思考与自测

- **自测 1**：在 VAE（变分自编码器）或扩散模型中，为什么不能直接从不可导的分布采样节点反向求导？怎么解决？
  > *解析*：随机采样算子无法传递解析梯度。解决方案是**重参数化技巧（Reparameterization Trick）**：将 $z \sim \mathcal{N}(\mu, \sigma^2)$ 拆写为 $z = \mu + \sigma \odot \epsilon$（其中 $\epsilon \sim \mathcal{N}(0, I)$ 为独立标准随机噪声），将随机性移到外部无梯度输入上，使得 $\mu$ 和 $\sigma$ 可以正常反向求导。
