# 提示链与并行化（Prompt Chaining & Parallelization）

> 掌握度：🟡 接触过

## 一句话直觉
提示链与并行化就像现代工业的**“流水线装配车间”**：复杂的大任务千万不要试图用一个巨型 Prompt 一步到位完成；将它拆解成工序 A、工序 B（串行链条），或者同时派 5 个工人分别审阅 5 个章节（并行处理），最后汇总质检。系统又快又稳，排查问题一目了然。

---

## 📌 架构拓扑对比

1. **提示链 (Prompt Chaining)**：串行工序，前一步的输出作为后一步的输入输入契约；
2. **分段并发 (Sectioning)**：将长任务并发发散到多个独立的 LLM 调用；
3. **投票集成 (Voting)**：同一个 Prompt 并发采样多个不同模型的意见，由裁判聚合。
