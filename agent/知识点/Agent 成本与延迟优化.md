# Agent 成本与延迟优化（Cost & Latency Optimization）

> 掌握度：🟡 接触过

## 一句话直觉
成本与延迟优化就是让 Agent 从**“烧钱喝油的研发 Demo，脱胎换骨成能规模化量产赚钱的商业流水线”**：通过模型级联（小模型打头阵，大模型压轴）、提示词缓存（大幅降费 80%）、预测性并行并发以及及时的上下文裁剪，把原来单次任务需要 30 秒、消耗 1 元钱，打到 3 秒内只要 2 分钱！

---

## 📌 工业落地 4 大降本增效利器

1. **Prompt Caching（提示词缓存）**：
   对于冗长固定的 System Prompt 和工具声明，命中厂商缓存后成本暴降 75%~90%，延迟减半；
2. **Model Cascading（模型级联降级）**：
   简单意图分类用极低成本小模型，仅在遭遇高难推理时才路由至旗舰顶配模型；
3. **流式预测与并行工具调用 (Parallel Tool Calling)**：
   支持大模型一次返回多个无依赖的工具调用请求，并发异步执行；
4. **上下文精简与剪枝**：
   任务阶段性完结后主动清理中间临时 Trace。
