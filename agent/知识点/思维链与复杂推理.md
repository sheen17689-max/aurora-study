# 思维链与复杂推理（Chain of Thought, CoT）

> 掌握度：🟡 接触过

## 一句话直觉
思维链就像小学生做奥数题时的**“草稿纸演算过程”**：如果直接要求大模型瞬间报出最终答案，模型就像不打草稿盲猜，正确率极低；但只要让它在草稿纸上写下第一步、第二步、第三步，借助前面写出的文字作为自注意力的输入锚点，复杂的逻辑推理难题就能迎刃而解。

---

## 📌 推理机制的形式化表达

标准提示（直接预测）：
$$P(Y \mid X)$$

思维链提示（显式引入思考路径 $Z = (z_1, z_2, \dots, z_k)$）：
$$P(Y \mid X) = \sum_Z P(Y, Z \mid X) = \sum_Z P(Y \mid X, Z) P(Z \mid X)$$

每个思考中间步 $z_i$ 都作为新的上下文，成为后续 Token 生成的强化注意力支架：
$$z_i \sim P(\cdot \mid X, z_1, \dots, z_{i-1})$$

---

## 🔍 主流思维链变体对比

1. **Zero-shot CoT**：Prompt 加上 "Let's think step by step"；
2. **Few-shot CoT**：人工提供 2~3 个完整的示范推导步骤与答案；
3. **Self-Consistency (自我一致性)**：多路径采样与多数表决；
4. **Tree of Thoughts (ToT / 思想之树)**：支持分支探索、回溯与剪枝 (BFS/DFS 状态空间搜索)。
