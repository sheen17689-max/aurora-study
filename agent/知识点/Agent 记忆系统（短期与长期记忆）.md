# Agent 记忆系统（短期与长期记忆）

> 掌握度：🟡 接触过

## 一句话直觉
Agent 的记忆系统就像人类的**大脑皮层与笔记本**：大模型有限的上下文窗口（Context Window）是**工作记忆（Working Memory）**，像眼前的工作台，容量小但拿取速度极快；而外部向量数据库与历史归档是**长期记忆（Long-term Memory）**，像身后的书架，容量无限，需要通过关键词或向量相似度（Embedding）索引「召回」到工作台上。

---

## 📌 认知记忆分层模型

```
                    ┌─────────────────────────┐
                    │     用户提问 / 当前任务  │
                    └───────────┬─────────────┘
                                │
                    ▼ 激活工作记忆 ▼
    ┌─────────────────────────────────────────────────────┐
    │  Working Memory (短期工作记忆 / 上下文窗口)          │
    │  • System Prompt (核心人设与指令约束)                │
    │  • 正在进行的思维链与工具执行观察 (Scratchpad)         │
    │  • 滑动窗口中保留的最近 K 轮活跃对话                 │
    └──────────────▲───────────────────────▲──────────────┘
                   │ 相似度召回            │ 实体关联
                   │ (Retrieval)           │ (Knowledge Graph)
    ┌──────────────┴──────────┐   ┌────────┴──────────────┐
    │ Episodic Memory (情景记忆)│   │ Semantic Memory (语义记忆)│
    │ • 过去的成功/失败交互经历 │   │ • 行业通用专业事实与知识库 │
    │ • 向量数据库 (Chroma/Milvus)│ │ • 结构化文档/实体三元组图谱 │
    └─────────────────────────┘   └───────────────────────┘
```

---

## 🔍 短期记忆的常见工程压缩策略

1. **固定轮数滑动窗口（Sliding Window）**：仅保留最近 $K$ 轮对话。简单直接，但容易丢失前文关键约束；
2. **递归摘要（Recursive Summarization）**：当总 Token 超过阈值时，触发后台小模型将较早的历史压缩成一段精炼摘要，放置在 System Prompt 之后；
3. **选择性剪枝（Selective Pruning）**：仅保留关键事实（如用户偏好、已确定的参数），剥离冗长的工具原始输出（Tool Outputs）。

## 思考与自测
- 为什么不能无限制地扩大上下文窗口（例如直接放进 1000 万 Token）来替代长期记忆系统？
- 在长期记忆召回中，单独使用向量检索（Dense Embedding）容易在哪些场景下失真？为什么工业界通常采用混合检索（Hybrid Search: 向量 + BM25）？
- 智能体在完成一次复杂纠错任务后，如何将本次「犯错并改正」的经历写入情景记忆，以便下次遇到类似任务时直接借鉴？
