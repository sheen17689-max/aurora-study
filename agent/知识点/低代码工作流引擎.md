# 低代码工作流引擎（Dify & Coze）

> 掌握度：🟡 接触过

## 一句话直觉
低代码工作流引擎就像**“AI 时代的 Scratch 积木与乐高工作台”**：通过拖拉拽节点（开始、LLM、条件分支、知识库检索、HTTP 请求、代码块），产品经理与运营人员无需从零敲 Python 代码，就能在图形化画布上像连线电路板一样拼装出工业级企业智能体与知识库问答机器人。

---

## 📌 核心节点架构设计

- **Start / End 节点**：定义出入参接口规范；
- **LLM 节点**：选择模型并配置 Prompt 模板；
- **Knowledge Retrieval 节点**：绑定知识库检索；
- **Code 节点**：运行极简数据清洗脚本（Python/JS）；
- **Condition 分支**：根据上游节点结果进行 IF/ELSE 路由。
