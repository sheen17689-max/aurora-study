# 智能体辩论与共识机制（Multi-Agent Debate & Consensus）

> 掌握度：🟡 接触过

## 一句话直觉
智能体辩论就像法庭上的**“控辩双方交叉质证与陪审团制度”**：单个模型很容易对自己输出的偏见或计算错误盲目自信；让正方 Agent 罗列证据，反方 Agent 寻找破绽，经过多轮公开辩论，裁判模型综合两方观点做出裁决，真相越辩越明。
