# 外部 API 与环境工具（External APIs & Environment Tools）

> 掌握度：🟡 接触过

## 一句话直觉
外部 API 与环境工具是 Agent 走出封闭训练集、**推开现实世界大门的“五官与双手”**：通过搜索引擎获取实时天气与突发新闻，通过企业内部数据库查询客户账单，通过发送邮件或调用 GitHub API 提交代码，Agent 才能真正具备产生现实业务价值的行动力。

---

## 📌 工具设计的「三要三不要」原则

1. **要精炼描述 (Description)**：工具的用途说明是模型选择该工具的唯一依据，必须写清「何时该调、何时不该调」；
2. **要类型约束**：参数严格使用枚举、正则表达式或类型限定；
3. **要幂等与只读标记**：对于写操作（如发邮件、扣费、删库），必须做安全分级。
