# 自我反思与错误校准（Reflexion & Self-Correction）

> 掌握度：🟡 接触过

## 一句话直觉
自我反思就像程序员写代码时的**“红绿灯单元测试与复盘日记”**：程序报错了不要立刻盲目乱改代码，而是先把报错信息（Traceback）完整读一遍，写下「为什么刚才会写错？关键变量的值是什么？下次该怎么修正？」，将教训化为记忆，下一轮尝试时成功率飙升。

---

## 📌 Reflexion 架构三大核心组件

1. **Actor**：生成具体的思维与行动轨迹；
2. **Evaluator**：打分或运行外部测试套件（如 pytest、代码执行环境）；
3. **Self-Reflection**：针对未达标的轨迹生成言语反思（Verbal Reinforcement），写入情景记忆指导下次迭代。

## 💻 极简反思循环伪代码

```python
def run_reflexion_loop(task_prompt, max_trials=3):
    memory = []
    for trial in range(max_trials):
        prompt = f"Task: {task_prompt}\nPast Failures:\n" + "\n".join(memory)
        trajectory = actor_llm.generate(prompt)
        success, feedback = run_test_suite(trajectory)
        if success:
            return trajectory
        reflection = reflection_llm.generate(f"执行失败: {feedback}，请反思改进。")
        memory.append(f"Trial {trial+1} 反思: {reflection}")
    return None
```
