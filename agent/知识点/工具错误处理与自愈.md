# 工具错误处理与自愈（Tool Error Recovery & Self-Healing）

> 掌握度：🟡 接触过

## 一句话直觉
工具错误处理与自愈就像给 Agent 配备了**“自动爬起来拍拍灰的摔倒修复机制”**：调用外部 API 遇到网络超时、404 未找到、或者 JSON 参数拼写错误时，优秀的 Agent 不会立刻对用户弹框报错认输，而是将错误原因作为新的观察读懂，自己调整参数重新尝试。

---

## 📌 自愈三步走生命周期

1. **捕获异常**：拦截 HTTP 状态码、Python 堆栈或数据格式校验报错；
2. **错误脱敏与格式化**：将底层的报错转换成包含纠错线索的结构化提示文本；
3. **自适应重试**：模型在下一轮思考中调整参数或改换备选工具。
