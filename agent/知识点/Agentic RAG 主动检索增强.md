# Agentic RAG 主动检索增强（Self-RAG & Corrective RAG）

> 掌握度：🟡 接触过

## 一句话直觉
Agentic RAG 就像一位**“懂得查字典的学者”**：传统的普通 RAG 是无论三七二十一，先去知识库查 3 篇文章强塞给模型；而 Agentic RAG 是模型自己判断「这个问题我懂不懂？要不要查？查出来的文档相关度高不高？不够我换个关键词重新查！」，化被动灌输为主动探索。

---

## 📌 Self-RAG 与 CRAG 架构流向

```
[用户提问] ──> [检索必要性判定] ── 不需要 ──> [直接生成答案]
                      │ 需要
                      ▼
               [执行向量检索] ──> [评估检索质量 (CRAG)]
                                          │
                  ┌───────── 质量差 ──────┴────── 质量高 ─────────┐
                  ▼                                               ▼
      [Query 改写 / 网页后备检索]                           [精炼上下文生成答案]
```
