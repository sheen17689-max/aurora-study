# 角色分工与专业智能体（Role-Playing & Specialized Agents）

> 掌握度：🟡 接触过

## 一句话直觉
角色分工就像剧组里的**“专业演员各就各位”**：给模型注入「资深 Python 架构师」的人设，它就会严谨考虑类型注解与异常处理；给它注入「挑剔的产品经理」，它就会关注用户交互细节。让不同的角色进行思想碰撞与同行评审，产出的方案远比单个平庸模型更出色。

---

## 📌 角色定义核心要素

- **Name & Role**：角色名称与职业头衔；
- **Backstory & Goal**：背景经历、核心追求与考核指标；
- **Exclusive Tools**：专属武器库（如只有 QA 角色配备运行测试的沙箱工具）；
- **Constraints**：严格的禁止行为清单。

---

## 思考与自测
- 为什么仅仅通过 System Prompt 赋予模型一个详细的 Backstory（背景故事），能显著改善其在专业领域的表现？
- 如何防止多个不同角色的 Agent 在交互中逐渐模糊人设、发生「角色同质化（Persona Drift）」？
