# 编排者与工作者模式（Orchestrator-Workers）

> 掌握度：🟡 接触过

## 一句话直觉
编排者-工作者模式就像**“项目经理与外包开发团队”**：项目经理（Orchestrator）负责把用户模糊的宏观需求拆解成互不依赖的若干个具体任务单，分派给不同的工种员工（Workers）独立执行，待所有员工交付工件后，项目经理负责整合验收，产出最终交付物。

---

## 📌 动态分解与上下文隔离

- **动态性高**：子任务的具体数量和类型事先不可知，由编排者根据输入动态决定；
- **上下文隔离**：每个 Worker 拥有干净独立的上下文窗口，彻底杜绝注意力稀释与 Token 爆炸；
- **容错隔离**：单个 Worker 失败不会导致全系统崩溃。
