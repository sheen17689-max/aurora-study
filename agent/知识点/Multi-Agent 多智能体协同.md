# Multi-Agent 多智能体协同（Multi-Agent Systems）

> 掌握度：🟡 接触过

## 一句话直觉
多智能体协同就像**“一支由不同专长成员组成的特种作战小组”**：一个人再全能，认知容量也是有限的；通过将复杂任务分派给情报分析员、先锋爆破手、医疗保障员协同作战，各司其职，不仅单兵上下文干净专注，团队整体战斗力更呈指数级提升。

---

## 📌 典型通信与拓扑架构

1. **层级司令部型 (Hierarchical)**：Leader 统一决策，Workers 汇报交付；
2. **流水线管道型 (Sequential Pipeline)**：上游成果作为下游原材料顺次流转；
3. **网状民主型 (Peer-to-Peer / Group Chat)**：所有智能体在一个群聊里按需发言或辩论；
4. **共享黑板型 (Blackboard Architecture)**：所有 Agent 读写同一个全局共享状态，无直接点对点耦合。
