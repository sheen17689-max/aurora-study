# Agent 可观测性与链路追踪（Langfuse & Phoenix）

> 掌握度：🟡 接触过

## 一句话直觉
可观测性与链路追踪就像给 Agent 系统安装上了**“全时无死角黑匣子与行车记录仪”**：Agent 执行失败了，不要瞎猜是哪一步出了问题；点开 Langfuse 追踪面板，每一次模型调用的 Prompt、Token 消耗、耗时、中间调用的每个工具入参与报错回包，以毫秒级树状图（Trace/Span）纤毫毕现。

---

## 📌 核心可观测数据模型

- **Trace**：一次完整用户请求的总生命周期追踪；
- **Span**：任务执行过程中的子阶段（如一次代码运行、一次向量检索）；
- **Generation**：具体的单次大模型调用，包含 Token 计数与输入输出；
- **Score / Evaluation**：人类标注或模型自动回传的满意度评分。
