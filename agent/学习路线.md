# 📍 Agent 智能体学习路线

> 主线：**Anthropic《Building Effective Agents》** 掌握架构思维 + **Hugging Face《AI Agents Course》** 动手实操
> ⬅ 当前位置：阶段 1 —— Agent 核心认知与 ReAct 闭环

## 阶段 1：Agent 核心认知与 ReAct 闭环（进行中）
- 里程碑：不依赖任何第三方 Agent 重型框架，用纯 Python + 原生 API 手写出具备 Thought-Action-Observation 闭环的最小 ReAct 智能体
- 材料：ReAct 原始论文 (Yao et al., 2022) ↔ Anthropic《Building Effective Agents》基础篇
- 收尾自测：能白板讲清 LLM 如何通过 Stop Token / Tool Call 信号交替转让控制权，完成多轮推理与执行

## 阶段 2：工具调用与 MCP 开放协议
- 里程碑：接入自定义本地 Python 工具，并手写一个兼容 Anthropic MCP 协议的本地 Server，让大模型自主操作本地文件系统与执行 Shell
- 材料：OpenAI Function Calling 官方规范 ↔ Model Context Protocol (MCP) 规范文档
- 收尾自测：讲清 JSON Schema 参数契约的校验机制，以及模型出现工具调用参数幻觉时的自愈重试策略

## 阶段 3：记忆系统与 Agentic RAG
- 里程碑：实现带有滑动窗口短期记忆 + 向量召回长期记忆的对话 Agent，并落地 Self-RAG（根据检索必要性动态触发搜索）
- 材料：MemGPT / Generative Agents 架构论文 ↔ LlamaIndex Agentic RAG 专栏
- 收尾自测：讲清语义记忆（Semantic）、情景记忆（Episodic）与工作记忆（Working Memory）的工程分层

## 阶段 4：工作流模式与 LangGraph / Multi-Agent 编排
- 里程碑：用 LangGraph 编排一个具备 Orchestrator-Workers（编排者-工作者）和 Evaluator-Optimizer（评估者-优化者）的生产级多智能体代码生成系统
- 材料：LangGraph 官方实战指南 ↔ CrewAI / AutoGen 核心架构
- 收尾自测：画出状态图（StateGraph）中的节点、边与条件路由，解释人机协同（HITL）的断点恢复机制

## 阶段 5：LLMOps、评测基准与工程落地
- 里程碑：在项目中接入 Langfuse 追踪完整 Agent 调用链，并针对 SWE-bench / GAIA 基准设计自动化评测与成本优化链路
- 材料：SWE-bench 评测体系 ↔ Langfuse 生产级监控文档
- 收尾自测：给出在生产环境中降低 Agent Token 消耗 50% 同时保持任务完成率的具体落地策略

## 下一步建议（每日更新）
- 冲击阶段 1 里程碑：精读《ReAct 范式》与《工具调用机制》，运行纯 Python 20 行极简智能体原型；体验大模型“思考 - 输出工具调用 - 捕获环境执行结果 - 总结回答”的单步生命周期。
